声稿 0.31.0 · 第一次制作日语卡拉 OK 字幕

完整解压运行包后双击 shengao-karaoke.exe，无需安装 Python、FFmpeg 或 Aegisub。
先用“作品 → 打开离线练习”熟悉流程；练习是合成音频，不代表真实歌曲精度。
详细步骤及图片见同目录“使用说明.md”。

1. 准备素材与原文
   拖入视频，粘贴每行一句原歌词。没有歌词时先识别初稿，再改字、拆合与确认原文。
   原唱／伴奏可各保存一个视频源，之后一键切换；字幕和人工校准共用。

2. 生成待审核初稿
   可选 ElevenLabs 或 Microsoft AI 转录，已有结果可在本机复用。
   DeepSeek 提供文字读音与译文；联网前在软件中配置密钥并选择要运行的阶段。
   付费等待状态不明时先查任务记录，不自动重复提交。保存工程可继续阶段流程。
   可在本机生成人声辅助，A/B 对比原声；TIFA 给出待审核歌声音节轴。
   字符时间、词组时间、均分估算与歌声候选分别显示，不能当作人工已确认。

3. 修正位置与音节
   先选择本句、多句、从这里到结尾或整首，再整体提前／延后；也可修正逐渐漂移。
   上一句、本句、下一句使用同一音频刻度。点击词组改假名，点击音节试听与拖边界。
   原版波形／频谱切换、三个滑条和 Aegisub 兼容音频键位仍可使用。
   “尾音细听”在主界面慢放、循环、增强／原声对照；普通定位或停止恢复常规播放。
   展开“音节拆分、合并与恢复默认”，先比较再采用；固定点、邻音和整词读音保持。
   固定音节起点或终点后，只重算其间未固定部分；候选先比较，采用可一次撤销。
   整体移动后的旧估算保护须明确允许后才重算，真正人工与固定点仍保留。

4. 校对日语读音
   选择词组，在本句比较候选、词典说明和已有转录／DeepSeek 依据，再试听采用。
   转录还是汉字时不当作实际发音证据；候选区本身不会自动调用 API。
   相同音节数保留人工轴和固定点；数量不同时保留旧轴并提示人工拆合。
   “记住当前读音”可选本歌或个人词典；管理窗口支持增删、导入合并和导出。
   本歌词典随工程，Ctrl+Z 可撤销；个人词典只在本机，另有撤销本次保存按钮。

5. 集中疑点与文字校对
   “集中疑点清单…”可筛选、定位、带前音试听，比较当前值与建议。
   可采用、手改、保留或暂缓；采用及处理记录可一步撤销，不等于已确认。
   相关内容变化或问题再次出现会重新待查，旧比较仍保留。

   注音、罗马音与译文：
   “汉字／假名对应…”可选自动、整词、手工范围或隐藏。手工范围从第 1 个字符计。
   例如“お星様／おほしさま”：星 → ほし，様 → さま；送假名“お”保留。
   “罗马音规则／手写…”先比较再应用；可设置拼写规则、长音和本工程新词默认。
   手写及来源不明旧拼法默认保留；假名改变后提示复核，可明确恢复自动。
   译文显示来源和实际字体宽度提示，可比较已保存的新建议；人工译文默认保留。
   注音位置、罗马音显示和译文修改不会改歌声时间；译文核对与日语确认分开。

6. 样式与输出
   日式双行模式支持上下句交替、提前接唱、留屏和汉字上方假名。
   待唱／演唱中／唱完可分别设置正文、假名、罗马音和译文的颜色与透明度。
   文字、扫亮前底色、描边、阴影和圆角底板独立设置，支持指定行覆盖及撤销。
   “歌名与歌手（左上角）…”独立设置文字、字体、配色、边距及显示时段。
   先导出样片检查，再输出 ASS 或 MP4。保存 .sgproj 可继续编辑。
   声稿 ASS 可保留本软件编辑资料；外部 ASS 特效保留与重新排版有明确提示。

保存与兼容
   本版保存第 13 版工程，读取 1–13；0.28.0 及更旧程序不能打开新版，请另存副本。
   带人声工程的 .assets 目录要一起保留。个人词典不随工程或发行包分享。
   人工确认、锁定、候选审核、保存和撤销是不同动作，AI 返回不表示已经校准。
   TIFA 模型限个人非商业用途。原程序与旧版本保留。

故障与待办
   后台失败先查看任务记录和错误阶段；已有结果可复用，原文件与人工修改保持。
   当前仍是 1.0 之前的功能版本，双行样式定稿、4K 代理、新手引导、恢复、压制队列和正式整首验收继续。
   当前开发／发行验收以使用说明和 GitHub 对应版本记录为准，不用合成练习证明歌曲准确率。
