声稿 0.27.0 · 第一次制作卡拉 OK 字幕

顶部五步流程默认收起，点“流程”展开。跟随每页的下一步提示即可。

1. 添加素材
   在欢迎页拖入视频或音频，也可以打开最近作品。
   视频下方“添加伴奏版…”选择另一份视频或音频；之后点“切到原唱版／
   切到伴奏版”即可切换。右侧小箭头可重新选择任一版本的文件。
   两个版本共用歌词、注音、样式与时间轴，不会重新转录。
   新源读取成功才切换；失败或取消保留旧源。时长不同需检查同步，
   程序不会自动拉伸字幕。源文件需事先准备，切换不生成伴奏。
   压制使用当前源，两个版本默认文件名分开。可一步撤销、保存后继续。
   有正确原歌词就粘贴，每行一句；它是分词和匹配的依据。
   没有原歌词，点“没有原歌词？先识别初稿…”，选择 ElevenLabs 或
   Microsoft AI。联网会上传音轨并使用额度；已有结果可本机复用。
   识别后先点“继续核对识别原文…”，试听、改字、拆合句子、删除
   误识别内容。原始识别保留，文字尚未成为字幕。
   初稿收拢日语识别空格，英文及之后手工输入的空格保持。
   “在光标处拆句”按字符证据或估算划参考范围，不是确定演唱音节。
   可以撤销／重做、还原识别文字、添加缺句；稍后继续保留当前修改。
   “原文核对好了，加入歌词”只在本机生成粗轴，不重新上传。
   文字加入后定位到首句，读音和时间仍需分别确认，可一步撤销回草稿。
   若识别期间已经粘贴正确原歌词，程序保留原文，只保存识别供复用。
   保存工程会带上未确认文字，重开可继续；任务记录也能恢复原文草稿。
   想先离线试用，可以点击“用示例练习一下”。

   听不清时，在音频区点“试听：原声”，首次在本机生成人声辅助。
   无需密钥，不上传素材；进度显示分段完成数，可以继续校对或取消。
   成功后试听、波形／频谱一起切到人声，再点一次回原声。
   播放点、慢放、循环与字幕轴保持；再次使用直接复用本机缓存。
   分离可能损伤弱尾音，请对照原声；成片仍使用当前原唱／伴奏源。
   保存会带上 .assets/audio 人声文件，重开默认原声，点击可再切人声。

2. 生成初稿
   同一副歌唱了多遍时，先把其中一句的分词、读音和时间校对并分别确认。
   在本页点“复用已校对副歌…”，选来源和原文相同的目标句，先试听。
   默认在本机按目标实际歌声重算时间，不复制来源节奏、锁定或确认状态。
   可只复用分词和读音，时间仍是本句旧范围内的估算；之后须校准。
   目标已有手工内容或确认时保留；不同原文、空格及标点不强行套用。
   结果先审核，可只采用部分、保存及一步撤销；来源变了不会套用旧建议。
   失败或取消保留读音及完成的声音结果，任务记录可继续原检查点。
   有转录时按整首顺序匹配，人工确认、手调或锁定的行保留并作为前后文。
   审核中的“整首顺序检查”列出漏识别／缺唱、重复段、顺序不同和未分配
   转录候选。先试听；文字不对应不等于实际缺唱，多余识别也不等于多唱。
   “定位到主界面校对”保留原内容并暂存建议；“限定正确时段重匹配”先
   保留结果，再只匹配该句，不重新转录。范围需自己试听，采用可一步撤销。
   原歌词空格、分词和读音保持。无对应句不硬造新时间；新建议不自动确认。
   新初稿默认保留间隔。校准页“检查空白…”按声音提出候选，先听再用。
   低能量、依据不足及人工边界保持；连续声音也不能确认读音或起音。
   固定 500ms 收拢移到进阶选项并默认关闭；它不能识别真实休止。
   点“按步骤生成初稿…”，选择离线、已有转录或联网识别；可另选
   DeepSeek 读音建议和 ElevenLabs 文字对齐。联网步骤会说明额度使用。
   “本机按歌声细分音节”使用真实音频和本次假名，TIFA 模型限非商业。
   可以选原声或已有对应人声；不上传、不使用额度，也不会改变成片音轨。
   先用转录确定大致位置；只有等分范围时，应先圈住实际唱段。
   一批歌词只加载一次模型，每句结果立即保留；取消后只补未完成句子。
   审核表显示“歌声候选／需手工”，不能把候选当作已确认时间。
   无结果行保留初稿；点“先手工修这一句”暂存建议并进入同一句编辑。
   暂存结果可从任务记录恢复。采用歌声候选可撤销，读音确认保持。
   已确认、锁定及有人工时间的行不进入此自动流程，已有译文保留。
   页面分别显示未选择、正在处理、完成和未完成的阶段，不等于人工确认。
   失败后点“查看／继续上次初稿流程…”，复用已完成步骤，也能先审核
   已完成的部分。无结果的联网阶段需检查服务记录后手动决定是否重试；
   程序不自动重发。保存重开工程后，在同一 Windows 用户下仍可继续。
   工程可带走，流程检查点另存在本机用户数据目录，未嵌入工程文件。
   普通任务记录也有继续入口；没有最终结果文件时仍可读取保存的阶段。
   原文、素材或服务配置变化时保留旧检查点，不混用新旧输入。
   任务期间改过或新确认的行，采用旧建议时会保留当前内容。
   单步离线分词、单句对齐、已有转录和 DeepSeek 工具在进阶区域中。
   所有建议先审核；只采用一部分时，其余建议会继续保留。

3. 本句编辑：原文、假名、音节和时间在一起
   ① 分词：直接在原文上点字前加分界，点已有分界合并。
   可先按词典分词或合为整句；查看哪些词组会重估，再应用。
   应用前不改时间轴；未应用的预览先应用或取消，再切句、保存。
   原歌词真实空格保留，不会生成只有空格的词组或空白音节。
   未匹配时先点“整句范围”，设置唱词开始／结束并应用，再分词。
   ② 注音：点原文或下表选词组，直接改假名，不再弹出窗口。
   只有改动词组会重估音节；其他人工读音、起止和音节保留。
   罗马音与译文在“罗马音与中文译文（可选）”中展开，罗马音列可显示。
   ③ 调时间：点演唱音节选中并定位，右键试听；下方时间框同步。
   起止框上方会显示字／词参考、估算音节、歌声候选或人工调整。
   “来源／提示”可比较原始依据和当前范围，筛选、试听并跳回对应音节。
   整体移动不会把均分估算变成逐音校准；“已保护”仅防止自动覆盖。
   时间确认仍保留原始依据，与读音确认分开；保存和撤销一起恢复。
   字／词参考不等于演唱音节；旧读音或旧边界无法对应时需要复核。
   拖原版时间轴边界也能调；右键试听，中键定位视频。
   旧工程有假名却没音节时，点“补全音节”先预览：按已有假名和词组
   范围均分，属于估算，需要试听。已有人工音节、读音与词组时间保留。
   锁定、没有有效假名或过短的词组会明确提示，不静默重写。
   青色轨是上句，紫色轨是下句；与当前句共用时间刻度。
   点邻句音节直接改对应音节，右键试听；橙色提示演唱重叠。
   小窗口收起参照按钮，但保留时间标记、音节选择与完整时间轴。
   视频下方“定位唱词”按播放点回到对应歌词／音节，不改时间；
   重叠时优先当前句，间奏选择最近句。点编辑区音节可反向定位画面。
   “本次确认”只决定底部按钮确认时间还是读音，全部编辑字段始终可达。
   读音与时间也能分别勾选确认；AI 初稿不会自动等于人工确认。
   Enter／G 始终按原稿顺序提交时间；底部按钮找下一句对应待确认内容。
   整体错位：展开“整体错位（本句／多句／整首）”，选修改范围，
   预览提前／延后、移到播放点或漂移校正；拖动整句使用同一范围。
   多选用 Ctrl／Shift；锁定冲突不静默跳过，整次一步撤销。
   配错副歌时指定正确区间，本地重新匹配后审核，不重新上传。
   “微调、空白与字幕留屏”中处理短空白、微调或修改画面出现／消失。
   留屏独立于演唱轴；全局移动同步，局部调整保留明确的手工留屏。
   拖到边缘会平移视野，Esc 取消本次拖动。Alt＋拖动临时移整句。
   尾音细听保留带前音慢放、循环、放大频谱、10ms 微调与单音假名。
   保存才写回，取消保留原值；可选辅音增强只用于试听对照。
   进阶区域仍有单独分词和假名窗口，需要时再使用。
   Ctrl+J 找下一疑点，F6 听本句，Ctrl+Enter 确认时间，Ctrl+S 保存工程。

4. 字幕样式
   点“颜色与演唱状态…”，先选全曲、本句或选中歌词，再选预设。
   正文、假名、罗马音和译文可分别设置待唱、唱中、唱完配色。
   文字、扫亮前底色、描边、阴影各有颜色和不透明度；描边／阴影可跟随扫亮。
   独立背景底板可按状态配色，另调边距、圆角。取消保持，采用可一步撤销。
   当前视频帧可预览三个状态，播放位置不变；没有提前或留屏时会提示。
   指定行自定义不被全曲模板覆盖，可恢复继承。本版详细颜色与固定点一起保存为第 11 版工程。
   “应用双行接唱 · 日式注音”：上左、下右交替，汉字上方贴假名。
   默认唱到一半提示下一句，上句从下句出现起保留约 3 秒。
   展开“调整接唱速度与光晕”修改提示进度、保留秒数和提前量。
   短句会给新句让位，间奏会清屏；提前显示不会改动演唱／音节时间。
   正文按原歌词的真实空格连续排列，假名不再撑开正文。
   用当前歌词对比字体和模板。原文与罗马音共用主字体，假名和译文
   可以另选字体。支持 TTF、OTF、TTC、OTC，并检查整首是否缺字。
   推荐日式接唱使用特粗明朝正文＋粗黑假名，另有简洁粗黑模板。
   眼睛按钮显示／隐藏字幕，方便比较；快捷键 Ctrl+Shift+P。

5. 导出作品
   Ctrl+S 保存可继续修改的 .sgproj 作品，保存后进入最近列表。
   ASS 保留卡拉 OK 高亮；也可导出 SRT 和纯文本。
   底部“先看 12 秒样片”和“导出成品视频”始终可见。
   只有音频也能导出 MP4，使用与预览一致的深色背景。
   完成后可直接播放成品或打开文件夹。

常用操作
   视频滚轮每格缩放 12.5%，双击恢复适合窗口。“放大视频”收起侧栏。
   时间轴上方“频谱／波形”直接切换；“显示设置”可查看完整快捷键。
   音频区右侧三个竖条：时宽＝时间缩放，高度＝波形／频谱增益，
   音量＝试听声音。前两个双击复位，均不改变素材或导出音量。
   找播放点／定位本句／放大所选只改变视野，不改歌词时间。
   Enter/G 按原稿顺序提交下一句，小键盘 +/- 改长度，B 试听所选/停止。
   Ctrl+Z / Ctrl+Y 撤销／重做；Esc 停止试听。
   拖上方刻度或滚轮平移，Ctrl+滚轮缩放；Shift 临时关闭吸附。
   时间轴获得焦点时：R 整句，S/空格 所选，Q/W 前后，E/D 开头结尾。
   方向键或 Z/X 切换音节，H 停止，A/F 平移。
   小窗口可用“歌词列表”切换左侧，或选择专注校轴／放大预览。

作品与字体资源请一起保留。最近列表只保存路径，不包含媒体副本。
本版读取第 1–11 版工程，新保存使用第 11 版；0.25.0 及更旧程序不能打开，请另存副本。
密钥加密保存在本机，作品和界面偏好不包含密钥。
网络超时不代表服务端一定未处理；先检查任务记录，再决定是否重试。

按歌声重算本句音节
   先确认本句的实际假名，用“整句范围”圈住本句（0.1–60 秒），
   再点“按本句原声／人声重算音节”。本机 TIFA 无需密钥或上传，
   模型限个人非商业使用，完整 CC BY-NC-SA 4.0 许可随包保留。
   整句头尾、原文和读音保持；人工音节与锁定词组固定，只重算其间。
   点击“比较并审核歌声音节建议”，逐音节比较新旧时间、带上下文试听，
   勾选采用后才写入，可一步撤销。读音不由此自动确认。
   无效或缺失音素保留旧时间；实际间隔不按固定阈值自动填平。
   处理期间的人工修改不被旧建议覆盖；结果可在任务记录恢复。
   新保存使用第 11 版工程，请另存副本，使用 0.26.0 或新版继续。

按声音检查多余空白
   点“检查空白…”，选这一句、多句、从这里到结尾或整首，默认本句。
   使用当前原声／人声，也可先准备人声辅助；不上传、不用 API 额度。
   分析长度上限不是填平阈值。伴奏持续而缺乏对应音素时保留待听。
   结果逐项带前后音试听，选保留、声音延续或人工延续，再采用。
   声音延续仍是待核对估算；人工延续明确记录为人工调整。
   仅延长前一高亮，下一音节起点与原词假名保持，可一步撤销。
   “去这处校准”直接跳回对应词组／音节，不先改时间。
   素材或歌词变动后重新检查，旧结果和迟到修改受保护。
   同一路径替换视频后，可在视频源菜单“重新载入当前源（保留字幕）”。

用正确位置引导局部重算（0.26.0）
   确认假名并补全音节后，点“固定位置后局部重算…”。
   选音节及起点／终点，试听、中键定位或拖播放滑条，
   点“读取当前播放位置”再“加入／更新固定位置”，也可输入毫秒。
   至少给两个点，默认只重算首尾点之间；范围外音节与人工内容保持。
   绿色虚线表示固定点；只固定所选一端，另一端仍需试听。
   本机生成后先比较并审核，勾选采用才写入，可一步撤销。
   草稿自动保存，关闭不改原轴；失败、取消保持整句原时间。
   任务记录可继续定位，或“返回本句手工校对”。素材或歌词变更时拒绝旧定位。
   固定点随工程与声稿 ASS 保存，后续重算继续遵守。
   选该音节点“取消所选音节的固定点”，时间不动，可撤销。
   工程格式 11，读取 1–11；0.25.0 及更早版本不能读取，请另存副本。

整体校轴后，再计算内部（0.27.0）
   仍点“按本句原声／人声重算音节”，遇到旧估算保护或已确认句时，
   先看“重新计算旧估算内部”的处理依据，再明确勾选允许重算旧估算。
   已确认句还须单独允许重新计算，采用后才恢复时间待确认。
   真正人工逐音调整、锁定、固定点、原文与读音保留，旧来源不明时不猜。
   本机生成不先改工程，返回后试听并勾选采用；读音状态保持，可一步撤销。
   失败区间、取消和迟到修改保留原数据，任务记录可继续或恢复审核。
   本版仍用第 11 版工程；0.26.0 可查看已保存工程，新流程与任务用 0.27.0。
