# 详细字幕颜色：下一独立功能版本的实现与验收范围

状态：开发分支已实现数据、编辑窗口和统一 ASS 渲染，发行验收中，ToDo 仍未勾选。对应完整 ToDo 第 6.7 项，优先于原计划的人工位置引导重算；这些新控件计划随 0.25.0 交付，0.24.0 不包含。目标是不写 ASS 标签也能制作唱前、唱中、唱后的配色。

## 用户操作

样式页提供“颜色与状态”入口。先选全曲、本句或选中歌词，清楚显示作用行数；默认编辑全曲模板，修改指定歌词时保留独立覆盖并可恢复继承。

三个状态分别为“待唱”“演唱中”“唱完留屏”。每个状态能设置正文、假名、罗马音和译文的文字颜色、描边颜色、阴影颜色及不透明度。演唱中另有未扫亮文字底色、扫亮后颜色和扫描方式；描边、阴影可选择跟随逐音扫亮或按整句状态切换。背景底板是独立选项，提供颜色、透明度、边距及圆角，不与阴影色混用。

初次打开显示易懂的色板和预设；颜色输入可用选色器或十六进制值。预览定位到待唱、句首、半句、句尾和留屏，使用当前歌词与视频帧。编辑是临时预览，采用后一步撤销；取消、重置、切换作用范围均不静默写入。无视频也可用棋盘／深浅背景查看透明度。

## 状态与现有工作流

“待唱”从显示开始到演唱开始，“演唱中”取实际演唱轴，“唱完留屏”从演唱结束到显示结束，边界采用半开区间；没有提前或留屏时不强行生成空状态。改变颜色不改歌词、分词、读音、音节时间、确认与锁定。

显示轴继续由 `presentation.display_windows` 计算；上下交替、提前接唱和手工显示时间保持。每句按自己的演唱与显示范围取状态，不能因下一句开始就让上一句提前消失。没有分词或音节时仍能显示整句并使用三状态配色，不伪造逐音时间。

自动匹配、读音建议、歌声对齐和换源都不能删除指定行的颜色覆盖。歌词删除后清理对应覆盖，撤销恢复；移动整句保持按歌词编号关联。外部 ASS 原样模式保持；编辑其配色时明确说明转为声稿排版，原始 ASS 保留且可撤销。

## 数据与渲染

现有 `Style` 只有文字、高亮和描边三种全局色；阴影色固定，不能满足本需求。新增可验证的状态配色结构和按歌词编号的局部覆盖，统一解析成每句有效样式。旧工程没有新字段时继续走旧渲染分支，保证旧项目像素不变；新工程格式升级并要求旧程序明确拒绝，避免丢失颜色后回存。

桌面以 `shengao/subtitles.py` 生成的同一份 ASS 驱动实时 libass、字幕导出、样片与整片。正文、假名、罗马音和译文复用当前实际字体度量与定位；不在预览控件单独涂色。

ASS 的 `\1c` 是主色、`\2c` 是卡拉 OK 次色、`\3c` 是描边色、`\4c` 是阴影／背色；各自 alpha 对应 `\1a`–`\4a`。界面不要求用户记这些标签。整句状态由时间切片或明确的转换标签实现；逐音填充沿用实际音节边界。若描边与阴影也跟随扫亮，则使用互补遮罩的前后图层，避免半透明颜色叠加或重复阴影。背景底板使用独立绘图层，位置按实际文字与注音包围盒计算，绝不能靠 ASS 背色冒充底板。

所有颜色、透明度、范围与样式引用先校验；标签只能由受控数值生成，原歌词保持转义。导出内嵌工程和字体资源沿用现有路径，保存重开能继续编辑配色。

## 验收

- 用红／蓝／绿等明显不同的配色，逐帧核对待唱、半句、唱完和留屏的正文、注音、描边、阴影及底板；检查 0%、50%、100% 不透明度和扫亮边缘。
- 用日语汉字假名、罗马音、译文、真实空格、多行及无音节句测试排版；两句交叠时都可见，切换双行不掉字。
