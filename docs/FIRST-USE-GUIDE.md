# 声稿首次使用指南（1.0 候选版）

写给第一次用声稿、也没用过 Aegisub 的人：先用软件自带的离线练习走一遍，再做自己的歌。每一步的完整说明和截图在同目录的“使用说明.md”；本页只讲第一次需要知道的事，以及默认设置、快捷键和已知限制。

## 1. 开始之前

- 需要 64 位 Windows（x64）。把运行包**完整解压**到一个你能写入的文件夹，再双击 `shengao-karaoke.exe`。不要在压缩软件里直接双击运行。不需要另装 Python、FFmpeg 或 Aegisub。
- 不联网也能用：离线练习、手工校准时间和读音、样式、样片和导出都在本机完成。
- 联网服务（ElevenLabs 或 Microsoft AI 转录、DeepSeek 读音与译文）需要你自己的密钥，由服务商按用量收费。密钥在顶部“服务设置”里填写，加密保存在这台电脑上。每次发送前软件都会先说明要发送什么并问你；勾选“以后同类发送不再询问”后才会跳过，之后也可以在“服务设置”里恢复询问。
- 本机歌声对齐使用的 TIFA 模型限个人非商业用途。声稿不宣称可用于商业制作。

## 2. 用离线练习走一遍（约 15 分钟）

练习是一段 8 秒的合成音调和一句示例歌词“今日も歌う”（今日／も／歌う），已经带有人工示例时间。它只用来熟悉操作，不代表真实歌曲的识别和对齐精度。

1. **打开练习。** 启动后停在第一步“导入素材”。在页面下方“第一次使用”里点“打开离线练习”。
2. **看清五个步骤。** 点顶部“流程”可以展开或收起五个步骤：导入素材 → 生成字幕 → 校准歌词 → 调整样式 → 导出作品。每页的“下一步”会指向现在可以继续的操作；按钮悬停可以看到它的作用。
3. **校准时间（“校准歌词”页）。**
   - `Ctrl+P` 播放／暂停，`F6` 试听本句。
   - 在时间轴上点一个音节就能试听它，拖动音节的边界可以改时间。
   - 时间轴上滚轮左右移动、`Ctrl`+滚轮缩放；右键试听音节；中键让视频跳到那个位置。
   - 底部“本次确认”选“本句时间”或“本句读音”，时间和读音分开确认。`Ctrl+Enter` 确认本句时间并跳到下一句还没确认的句子。
   - 改错了按 `Ctrl+Z` 撤销，`Ctrl+Y` 重做。
4. **调整样式（“调整样式”页）。** 默认样式是“清晰通用”。改字号或颜色时预览会立刻变化，不会改动任何时间。
5. **导出（“导出作品”页）。** 先点“先看 12 秒样片”检查效果，再选“导出字幕文件…”（ASS，也可以导出 SRT 或纯歌词）或“导出成品视频”（把字幕烧进画面）。压制在后台运行，期间可以继续编辑，也可以取消。
6. **保存。** `Ctrl+S` 保存为 `.sgproj` 工程，以后可以继续编辑。

## 3. 做自己的歌

1. 新建作品（`Ctrl+N`），把视频拖进窗口，粘贴每行一句的原歌词。没有歌词时可以先让联网服务识别一份初稿再改。
2. 在“生成字幕”页选择要运行的阶段：识别、读音与译文、本机歌声对齐。每个阶段都可以单独运行和取消；已经得到的结果会保存在“任务记录”里，可以直接复用，不用重复付费。
3. AI 给出的时间、读音和译文都只是**待审核的初稿**，不会自动当成已经确认。按句检查，用“集中疑点清单…”集中处理可疑的地方。
4. 本机歌声对齐只用 CPU 计算，整首歌需要较长时间；可以随时取消，下次接着做。
5. 视频很大或预览卡顿时，打开“作品 → 轻量视频预览…”准备一份最大 720p 的预览视频；转录和最终输出仍然使用原片。

## 4. 保存、恢复与版本

- 工程只**引用**视频，不复制视频。视频移动或改名后，用“作品 → 重新定位媒体…”找回。带人声分离结果的工程，旁边的 `.assets` 文件夹要一起保留。
- 软件每 15 秒在本机写一份恢复记录。程序意外关闭后再次启动，会问你是否恢复上次没保存的修改。
- 编辑中大约每 5 分钟、以及每次保存时，会在本机记一个版本。“作品 → 版本历史…”可以逐句比较并恢复旧版本。
- 打开一个已经损坏的工程时，原文件保持不动；如果本机版本记录里有它的较早版本，软件会问你要不要打开那份记录，保存时请另存为新文件。
- 本版保存第 14 版工程格式，可以读取第 1–14 版。0.29 及更旧的程序打不开新格式，需要给旧版本用时请先另存一份副本。

## 5. 默认设置

下面是第一次启动时的设置。除工程样式外，这些都只影响本机，不写进工程。

| 设置 | 默认 | 在哪里改 |
|---|---|---|
| 顶部五步流程 | 收起 | 顶部“流程” |
| 校准页视图 | 视频＋时间轴 | 校准页底部视图选择 |
| 时间轴显示 | 频谱 | 时间轴上方的频谱／波形选择 |
| 本次确认 | 本句时间 | 校准页底部“本次确认” |
| 播放速度 | 1× | 底部速度选择（0.5×、0.75×、1×、1.25×） |
| 音量 | 70 | 底部音量滑条 |
| 预览字幕 | 显示 | 预览上的字幕开关或 `Ctrl+Shift+P` |
| 自动恢复记录 | 每 15 秒一次 | 不需要设置 |
| 新工程样式 | 清晰通用：Noto Sans CJK JP，正文 62、假名 28、罗马音 30、译文 32，白字，高亮 #73e8bb，显示假名、罗马音和译文，逐句显示 | “调整样式”页 |
| 罗马音规则 | 平文式（Hepburn），长音保留假名拼写（ou／oo 等），助词 は／へ／を 写作 wa／e／o | “罗马音规则／手写…” |
| 样片 | 当前句前 1 秒起，12 秒（可设 2–60 秒） | “导出作品”页样片设置 |
| 输出尺寸 | 分辨率跟随原视频（也可选 1920 × 1080 或 1280 × 720） | “导出作品”页 |
| 画质 | 标准画质 · 6 Mbps（也可选 较高画质 · 12 Mbps） | “导出作品”页 |
| 编码器 | CPU 编码 · H.264 / AAC（显卡编码需要硬件与驱动支持，失败时请改回 CPU） | “导出作品”页 |
| 输出文件夹 | 上次选的文件夹；没有时用工程所在文件夹，其次是视频所在文件夹，再其次是“视频”文件夹 | “导出作品”页“输出目录”旁的“更改…” |
| 预览用 GPU 缩小视频帧 | 开启（不支持或出错时自动改用常规预览） | “作品 → 预览与后台设置…” |

| 轻量视频预览 | 不使用，直接预览原片 | “作品 → 轻量视频预览…” |
| 联网前确认 | 每次都问 | 确认窗口里的“以后同类发送不再询问”；“服务设置”里可恢复询问 |
| 时间轴键位 | 下表的 Aegisub 默认键位；输入文字时暂停小键盘 Medusa 键位 | “作品 → 打轴快捷键设置…” |

## 7. 已知限制

- 只支持 64 位 Windows。
- 主要面向日语歌词；其他语言的读音和罗马音没有专门处理。
- AI 的识别、读音、译文和歌声对齐都只是初稿，必须人工检查。离线练习是合成声音，不能说明真实歌曲的精度。
- TIFA 歌声模型限个人非商业用途。
- 本机歌声对齐只用 CPU，整首歌较慢；可以取消、之后继续。
- 联网服务需要你自己的密钥并按用量付费；服务商改接口时可能需要更新软件。
- 很长的工程、4K 视频和长时间连续播放的性能还在做最终验收；卡顿时先用轻量视频预览。
- 工程只引用视频，视频移动后需要重新定位。
- 第 14 版工程不能用 0.29 及更旧的程序打开。
- 外部 ASS 里的部分特效不会转换成可编辑的声稿内容，导入时会提示保留或重新排版。
- 显卡编码取决于显卡和驱动；不可用时请改用 CPU 编码。
- 1.0 发布前还要完成：正式歌曲整首验收、真人新手实际试用、干净 Windows 上的安装试用和最终性能验收。

## 8. 出问题时

- 后台任务失败：点底部“任务记录”，查看失败的阶段和原因。已经得到的结果可以从这里恢复或复用，原文件和人工修改不会被改动。
- 付费任务状态不明时，先在“任务记录”里确认，软件不会自动重复提交。
- 需要别人帮忙排查：“作品 → 导出诊断报告…”。报告不含密钥、歌词和素材文件名，发送前可以先打开检查。
- 设置文件或任务记录损坏时，软件会把原文件改名保存并改用默认值，不会删除你的文件。
