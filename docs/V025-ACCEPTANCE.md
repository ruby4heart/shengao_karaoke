# 声稿 0.25.0：详细颜色与演唱状态

状态：开发分支验收中，尚未完成独立运行包与 GitHub 交付。对应 ToDo 6.7，完成前保持未勾选。

样式页“颜色与演唱状态…”提供全曲、本句和选中歌词范围，四个文字层和待唱／演唱中／唱完留屏状态。文字、未扫亮底色、描边与阴影分别配置 RGB 和不透明度；正文与假名的描边、阴影可随扫亮切换。整句背景底板独立绘制，带三状态配色、边距和圆角。预设、恢复继承、原有模板和重置均先预览后采用。

预览保持可见：正常窗口在侧边，小逻辑屏幕在顶部；调色控件滚动，采用／取消保持在底部。状态选择与预览按钮联动，视频使用当前帧，播放器不跳转。没有提前显示或留屏时明确说明，不为展示颜色改动显示轴。未分词句、罗马音和译文只按整句状态切换，不生成虚假的逐词时间。

指定行自定义保持独立，后续全曲模板不覆盖；恢复继承可清除局部覆盖。颜色修改不改变歌词、分词、读音、时间、锁定或确认，采用为一步撤销。原 ASS 转换为声稿排版会说明，原文本保留且可撤销。迟到配色变化时不覆盖当前版本。

所有输出使用同一份 ASS：独立颜色与 alpha 映射标准通道，逐音节使用实际已有时间，互补遮罩实现描边与阴影的扫描；底板在单独图层。旧工程没有颜色配置时走原有渲染分支。保存格式升级为 10，读取 1–10；0.24.0 及更旧程序拒绝 10，建议另存旧作品。

开发检查包含真实 Qt 编辑、取消、作用范围、便携字体保存／ASS 重开、一次撤销、来源变化保护与小窗口按钮。实际 libass 检查三状态文字、描边／阴影扫描与圆角底板透明度；实际 FFmpeg 在三个时间点与预览比较，另在完整桌面流程中比较双行与四个文字层。纯色计数样例使用软件内置的大字粗黑模板，避免小号细字抗锯齿造成色样计数失真；检查不评估歌声精度。

新增 16 项完整桌面检查已分别在普通和 150% 缩放开发实例执行，发行时仍需完整回归、完整桌面流程、两种独立包、原版音频绘图和归档验证。最终数据以发行审计及冻结证据为准，不能把局部开发检查写成完整发行通过。
