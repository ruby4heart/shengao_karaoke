# 整体校轴后的明确内部重算

0.27.0 补齐 ToDo 4.7、8.5 中的一处衔接。整体平移、分段校正或整句时间确认会把内部也标为人工保护；其中一些仍是估算或未经逐音人工调整的候选。用户不应靠改假名再改回来解除这些保护，也不能让自动重算静默覆盖真正人工校准。

## 选择与保护

沿用“按本句原声／人声重算音节”按钮。没有旧保护、且本句时间未确认时保留原来的直接流程；遇到可识别的旧估算保护或已确认句，先显示待计算与保留的音节。默认不勾选释放旧保护；已确认句还须单独允许重新计算。两项许可独立，生成阶段不改变工程。

只有来源明确、范围记录仍与当前位置一致、没有逐音人工边界记录的旧保护可以选择重算。人工时间、逐音边界调整、锁定、双端固定、导入或来源不明的旧人工记录保守保留。单端固定继续约束该端；若另有其他人工保护，不因为存在单端固定就绕过这些保护。整句和人工词组的外缘保持，读音、译文、分词与范围外内容不变。人工来源或逐音调整记录独立于旧 source 标记判断，即使旧标记不一致仍保留。人工词组外缘不冒充首尾音节边界：允许外缘与真正起音间存在留白。

## 请求与采用

规划保留完整原始行、准备行、声音子区间、保护说明及明确选择。模型只接收本地 PCM 与读音。候选保留原始音素证据；旧估算来源和被实际重算的位置另行记录。失败区间恢复原来的时间、来源和保护，不只保留数值。全部失败、取消或请求无法落盘时不改变工程。部分成功不保存为完整缓存，下次明确重试会重新计算，避免把失败区间永久当成已完成结果；完整结果仍可复用。

采用时从原始行重新推导许可和保护范围，不信任任意传入的释放名单；与当前行和确认状态不符、缺请求或更改固定点时拒绝采用。已确认时间只有经过明确允许且实际采用后才恢复待确认，读音状态保持。一次撤销恢复此前时间、来源、保护和确认。工程格式仍为 11，新依据保存在原有时间证据字段中。

任务请求、暂存审核和自动恢复携带原始选择。任务记录继续时核对工程、素材和完整本句版本，先回校准页再重新打开说明窗口；已完成结果也可直接恢复审核。已有逐音人工边界也可只读地作为固定点窗口的范围参考；时间不可改，不因此重复建立固定标记，移除草稿参考不会解除人工轴。词组编号与音节编号分别显示，完整原词放在提示中，避免长词组遮住当前音节。

此流程不新增主界面按钮，不改变 Aegisub 兼容键位或原版绘图。

## 验证与范围

核心及真实 Qt 检查覆盖整体平移后的旧保护、两项许可、人工来源、锁定、固定点、失败恢复、审核、保存、迟到编辑及一次撤销。公开 PJS056 的受控错误初稿实际整体移动 700 ms，保留一个人工参考音节和一个固定起点，经真实 TIFA 生成其余 18 摩拉；17 个未固定起点单独记录误差。该样本训练重叠未知，不是独立正式 MV 精度或成品验收。

本项不等于完成第 4.7、8.5 的其他工作：弱尾音与特殊音节拆合、更多来源的一致恢复和故障验证继续；无法明确区分来源的旧人工记录仍须保守处理。当前发行验收状态见本版验收文档。
