# 声稿 0.16.0：可恢复初稿流程

新的五阶段入口复用已有单步服务；工程 schema 保持 4。完成的检查点保存在当前 Windows 用户目录，不嵌入工程、不包含密钥。旧发行版和原始 Aegisub 保留。

| 要求 | 实现与证据 |
| --- | --- |
| 一次选择、逐阶段显示 | 离线／已有转录／联网识别，可选 DeepSeek 和文字对齐；未选阶段跳过，区分本机与联网；实际 Qt 对话框与独立后台进程 |
| 原歌词优先 | 原文、编号和顺序逐阶段验证；复用转录核对素材版本；不把识别空格写回原文；缺少原歌词时明确要求先准备 |
| 可恢复与部分审核 | 每阶段保存输入签名、素材指纹、服务配置和结果校验；完成步骤复用；中途失败、取消和最终 IPC 缺失仍可恢复已保存初稿 |
| 联网不重复提交 | 未完整返回的联网阶段需明确手动选择重试；全部所需密钥先检查；OS 互斥锁防同一流程并发；缺少／损坏检查点不自动重做 |
| 保留人工结果 | 已确认时间、锁定和人工轴不进入新流程；已确认读音和已有译文保留；运行中修改或新确认的行由原快照及确认快照保护 |
| 使用与重开 | 主页面和任务记录有继续入口；同工程重开复用同本机检查点；部分结果审核、一次撤销和保存重开通过真实 Qt 操作验证 |
| Windows 文件占用 | 原子写文件遇到短暂占用，只重试本地替换；不重发 API；永久失败保留旧文件并清理临时文件 |
