# 在本句比较读音候选

第 4.1 项围绕当前选中词组展开：当前假名、固定 Janome/IPADIC 的同原文多读法、对应时段的转录假名、仍对应当前词组的已保存 DeepSeek 文字建议。原歌词保持，实际词典条目按完整表面词筛选，不能拿前缀条目的读音冒充整词。较长未分词内容先提示切分，避免在界面线程无限查询。

所有来源都是文字候选。转录仍为汉字、覆盖不足或多个识别互相重叠时不拼出假名；另一重复段不作为本词依据。已知转录与当前素材不符时不提供该记录的候选，未绑定的旧记录明确说明。文字模型不提供声音边界。查看、试听和选择列表不联网，既有 DeepSeek 操作仍须明确触发、审核与采用。

候选与当前假名、文字依据和处理说明在同一编辑区，时间页收起，长依据可以滚动。试听使用当前原声／人声轨，范围为词组前后各 180 毫秒，无可读取素材时不可试听。候选数量和词典成本不是识别置信度。

采用前重建变化计划，核对完整原始行、工程、素材和确认状态。相同摩拉数时保留起止、自然间隔、人工／固定边界及原始时间依据，仅替换读音标签；旧声音依据仍保留旧假名，不声称验证新读音。数量不同时，只能重新估算没有逐音人工／固定点的内部；真正人工、未知旧人工、固定点或锁定不会静默释放。人工外缘保持，其他词组保持。上方既有直接填写是假名的显式重建入口，其更完善的拆合仍属第 4.7 项。
