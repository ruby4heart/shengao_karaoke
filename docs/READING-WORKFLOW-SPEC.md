# 0.28：日语读音校对整组目标

按 2026-10-25 用户要求，本版合并 ToDo 4.1–4.5、4.8，完整实现并通过验收后一次发行。当前实现与缺项分别记录，不把六条计划当成完成。

1. 在本句逐词比较当前、词典多读法、转录假名和 DeepSeek 文字依据，带上下文试听后采用；汉字识别不当作发音证明。
2. 歌曲专用和个人读音词典可选择复用，记住特殊唱法与名字；可以管理、导入、导出，保存工程保留本歌词典，个人数据留在本机。词典候选不自动改原文、读音或人工时间。
3. DeepSeek 提供文字读音和翻译建议，声音与时间依据来自音频分析；请求范围、付费重试、人工保护、结果审核与缓存继续生效。不向模型索要或采用编造的声音边界。
4. 汉字与送假名可以自动对应，熟字训可整词注音；人工能指定原文与假名范围，预览、ASS 与成片使用同一映射。改变分词或读音时保留未受影响的映射，冲突明确指出，不静默乱配。
5. 假名确定后按所选罗马音规则生成，明确自动与人工覆盖；手写保留，可恢复自动。范围选择、原文、读音、时间和锁定互不冒充。
6. 译文区分初稿与手改，保留人工内容，提供长度／显示提示和可比较的新建议；翻译不会改写原歌词或读音。

词典、注音映射和罗马音设置需要明确的工程格式及迁移门槛。旧不可识别格式应拒绝而非丢掉新数据；声稿工程与 ASS 保留新数据，历史任务的空字段序列化保持兼容。新增的个人词典和设置不得进入公开发行资产。

验收同时覆盖手工轴和固定点、锁定、已确认状态、迟到修改、保存重开、ASS、一步撤销和正常／150% 独立包。真实服务、模拟接口、本地词典与合成练习分别说明，不用文字候选数量或模型分数宣称歌曲准确率。当前正式 MV、真人新手和干净 Windows 门槛继续。
