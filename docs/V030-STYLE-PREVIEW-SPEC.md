# 0.30：双行样式、可读性与大视频预览

本版功能交付为ToDo6.1–6.6六条。2026-10-29按用户更新的目标调整顺序：先完成未实现功能，性能优化留到最后，并提供可选入口。0.30按6.1–6.6六条功能交付；11.2继续待办，原250ms／500ms等门槛与失败记录保持。功能验收不冒充性能整轮通过，完整1.0仍须完成最终性能、真人新手、正式歌曲与干净Windows验收。 当前剩余5组、35条。旧0.29源码、归档及已核验Release保留。

目标流程：选双行 → 同刻度看前后句的留屏与演唱 → 直接拖显示边界并看效果 → 用实际歌词与静止视频帧比较字体 → 定位并修正长行、密集注音与缺字 → 大画面试听 → 可选 4K 代理 → ASS、样片及原片成片共用排版。

1. 验证普通、短句、密集接唱、间奏和真正重叠的演唱。上左／下右、提前接唱、留屏、逐音扫亮与汉字上方假名保持；不能为腾位置删除正在唱的句子。手动提前下一句后，上一句的自动留屏相应更新；明确的手工消失时间不能被自动让位覆盖。
2. 原版音频绘图外增加同刻度的留屏条。前／本／后句及演唱参考清楚，拖动、键盘微调只改出现／消失；边界不能裁掉演唱。松开一次提交、Esc 取消、一步撤销；迟到内容或素材变动拒绝旧拖动。复杂原 ASS 先明确选择声稿样式。
3. 字体比较用本工程歌词、假名和当前静止视频帧，提供有许可的内置正文／假名组合、字号、描边和背景对比依据。预览不改工程、播放点或源，采用范围明确且可撤销，已有详细配色保持。
4. 检查长行、密集注音、缺字、安全区、多行及重叠，并可直接进入修正。只改本句外观的字号及明确词界换行保持原文和全部轴；没有词界时直接进入分词，不编造汉字读音对应。原文或分词改变后旧换行提示复核，不能导致工程打不开或静默丢失设置。预览／ASS／样片／全片一致。
5. 大视频、滚轮缩放、适合窗口与可拖分隔在 960×680、1280×800、正常／150% 下可用。空间分配清楚，保留前后句、三个滑条和常用编辑入口，新工具不挤掉波谱。
6. 4K 代理是可取消的本机缓存任务，默认使用原片输出。原路径和时间基准保持；核对音频及帧位置后才切换。原唱／伴奏、原声／人声各有明确含义；更换素材、同路径变动和无效缓存不套旧代理。可切回原片，失败不影响原片、轴或已有成果。
7. 固定硬件、内存压力、媒体、冷热缓存和测量方法，记录启动、切句、拖轴、试听、4K／代理及后台任务时的交互。各项先定可接受标准再测量和修复；本机结果不冒充所有硬件、干净 Windows 或真人新手认证。

先完成留屏条与数据守卫，再完成字体／逐行外观和一致渲染，随后代理与布局，最后性能及整条工作流。新增序列化数据才提升工程格式，用实际旧发布解析器源码验证拒绝新版，保持读取旧格式。

验收覆盖纯数据边界与保护、真实静音离屏 Qt 操作、保存／声稿 ASS／撤销、受控视频一致性；指定 MV 只用于本地代理和性能，不上传原片或私人工程。最终仍须当前源码全量、开发／正常包／150% 包、原版像素对照、依赖、完整归档和 GitHub 四份资产核验。六条功能按当前源码、三种运行实例和原版绘图验收完成；11.2保留最终性能待办，不以功能发行代表压力测量通过。
