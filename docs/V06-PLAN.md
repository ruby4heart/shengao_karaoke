# 0.6 人工校对与转录辅助读音

本轮要求及验收依据（完成前逐项核验）：

- 去掉分词条人为添加的空格及等宽字格，按原歌词自然字宽显示；原文本身的空格保持。实际渲染与点击回归证明。
- 卡拉 OK 模式支持直接拖动整行开头、结尾，扩大命中范围和手柄；保持毫秒与 ASS 厘秒一致、禁止交叉、支持提交与撤销。实际控制器和鼠标交互验收证明。
- 增加逐行／逐词的起止时间校对、微调、边界试听、自动定位缩放、确认后下一待校准行。用真实控件及合成媒体验证，确保选中行和草稿不会丢失。
- 识别导致的短空隙可收拢，长停顿可见且保留；人工保护结果不被静默改写。用短间隔、长静音、锁定、已确认和人工音节回归证明。
- 日语汉字读音复核结合当前媒体的转录、原歌词上下文、词典和已有读音；离线候选与 DeepSeek 复核均先审核。不能将词典猜测标成实际唱法；保留人工注音和读音未变的人工时间。
  时间确认与注音保护分开：已确认时间不被自动重打，仍可二次复核读音；明确手改注音默认保护，旧版来源不明读音可选择保留。
- 展示读音修正依据、原／建议读音与对应转录，允许试听、取消和应用；无转录时明确显示，不把无关媒体记录当依据。
- 改善主要制作流程和提示，修复所发现的草稿、时间精度、空白、读音结构及任务恢复问题；进行完整运行包回归和原生图像验收。
- 提供新版独立运行包、源码和说明；原软件和旧发行版本保留，不自动请求真实付费 API，不使用 Computer Use。

最终结果与未解决限制记录在 V06-USABILITY.md；当前本文件是验收清单，不是完成声明。
