# 0.3 无时间歌词匹配与整体界面改造

本轮目标来自用户：不必依赖 LRC，能把转录结果按正确歌词的相似度分行；整体 UI 更现代并脱离 Aegisub 原始边框，同时继续发现并修复实际问题。

## 交付要求

1. 默认支持普通歌词：视频 + 无时间原文 → 转录并本地匹配 → 审核 → 人工校准。已有成功转录可复用，不再次上传。
2. 匹配保持原文和原分行，按顺序处理转录插入、遗漏、错字、标点、全半角与片假名 / 平假名差异。显示文字相似度、覆盖情况和识别片段。重复副歌、匹配不足和未匹配行要明确标记，低可信建议默认不勾选。
3. 匹配只提供粗轴，不声称是精确声学时间。词级时间拆到字符或插补时间必须标为估算；没有依据的行不能伪造成功。保留 ElevenLabs 精确对齐入口供进一步校准。
4. 允许限定已有时间范围以定位副歌；保护锁定和处理期间的人工改动；匹配数据随 ASS / JSON 保存恢复，并进入字幕检查。
5. 改造整个默认窗口：自定义简洁顶栏与窗口控制、现代歌词卡片列表及筛选、清爽播放 / 时间轴工具和当前行编辑。移除默认原生菜单栏、工具条和复杂样式编辑框；高级命令保留在菜单 / 面板中。保留成熟原生波形、频谱和打轴引擎。
6. 完整验证最大化 / 还原、关闭保护、筛选与选择同步、编辑撤销、播放、匹配结果恢复和导出。界面验收包含整个窗口，不只截右侧栏。
7. 修复改造过程中查明的问题；保持原始源码及旧版本不变，生成 0.3 运行包、对应源码、说明与校验文件。

## 验收方式

- 匹配边界测试：跨 ASR 分段、错字与插词、缺句、重复副歌、限定范围、日语归一化、时序、原文覆盖、锁定和相似度标记。
- 模拟真实回环 API 验证转录匹配单次请求与缓存复用；本地匹配不能要求密钥或联网。
- 原生集成验证审核、保护、保存重开和既有功能。
- 使用软件自身离屏实例与控件渲染核对完整窗口、列表和各工作流阶段；不使用 Computer Use 控制其他窗口。
- 完整包验证独立运行、运行时、新依赖授权、中文路径、安装、压缩包完整性、源码一致性。

## 实现与验证结果

0.3 功能已实现，使用最终包验证：

- 后端 32 项测试通过；实际回环 HTTP 验证转录并分行、修改原歌词后复用缓存及本地匹配，总上传一次。转录成功而匹配失败时保留结果。
- 392 项 C++ 测试（40 组）及 LuaJIT 通过。
- 原生集成 112 个检查点通过，覆盖卡片搜索筛选、原生选择同步、编辑与撤销、匹配资料、关闭草稿的取消 / 放弃 / 保存、最大化还原、保存重开、原生时间轴、循环慢放、四阶段整窗与窄窗口。
- 独立运行包通过本地匹配、加密配置、ASS / JSON / SRT / TXT、FFmpeg 渲染与音轨提取、隔离安装验证。RapidFuzz 的授权文件随包分发。
- 整窗预览位于 images/window-stage-1.png 至 window-stage-4.png；侧栏预览另存。仅渲染软件自己的离屏实例；卡片、表格、波形与音节区复用本程序绘制函数，OpenGL 画面由同一原生字幕渲染器合成到实际视频区域。
- 发行目录为 dist/ShengaoKaraoke-0.3.0-final-win64；源码为 ShengaoKaraoke-0.3.0-source.zip。压缩包与源码一致性、依赖和 SHA256 由 scripts/check-release.py 记录。

查明并修复了视频容器零尺寸、音频面板宽度缓存导致侧栏重叠、当前行编辑不可见、长状态被裁切、转录返回后匹配失败丢失已有转录、环境声进入歌词，以及构建补丁重复插入头文件的问题。适配脚本重复运行已核对源码和时间戳不变。

## 仍需人工判断的范围

文字匹配是粗轴；相似度不是声学置信度。汉字与不同写法的假名、当て字、漏唱、合唱和混音可能造成弱匹配。词级时间细分和补时明确标为估算；保护行不会自动重打轴。应用可靠建议后，仍需试听与必要的 ElevenLabs 对齐。

本轮未使用 Computer Use，未使用真实密钥、未上传用户歌曲，没有真实付费 API 成功记录。侧栏未提交草稿尚不属于原生自动保存内容，应及时保存到工程。

## 后续建议

1. 增加可选人声分离，改善伴奏较强的演唱识别，并保留原音轨供校准。
2. 为汉字、假名演唱音节和罗马音提供独立的可视化轨道，进一步简化复杂音节编辑。
3. 增加侧栏未提交草稿的崩溃恢复和可命名工程快照。
4. 增加多处人工锚点与多轮候选比较，用于处理高度重复的副歌。

以上是后续范围，本版不将这些功能列为已实现。
