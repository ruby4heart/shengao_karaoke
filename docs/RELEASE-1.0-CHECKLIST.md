# 正式版还缺什么

复核日期：2026-10-25。目标为个人非商业用途的 Windows 1.0。0.25.0 已发布并完成详细颜色、正常／150% 独立运行包及匿名下载核验；0.26.0 完成人工位置引导重算，0.27.0 已公开发布并核对四份资产摘要；0.28.0 六项读音功能已通过当前源码和三种实际运行门槛，公开 Release 的标签提交、四份附件指纹及匿名下载也已核验；已有功能与历史证据见各版本验收，不据此将尚未验证的正式场景记作完成。GitHub 交付以各版发布回执和远端资产核验为准。

正式版须让不会 Aegisub 的人完成：视频 → 原歌词 → 可恢复的自动初稿 → 整体／局部校轴 → 读音与音节校对 → 日式双行注音 → 样片 → ASS／成片 → 保存续做。AI 结果始终允许人工改、比较、撤销和恢复。

## 还有多少

当前剩余 **8 组、49 条功能／验收待办**，GitHub 的 **4 条持续交付要求**另计。按当前未完成项分为：细听／拆合 2 条、集中疑点 5 条、样式与歌名／歌手 5 条、视频与性能 3 条、新手工作台 7 条、恢复／诊断／服务验收 8 条、导出 6 条、正式歌曲与发行验收 13 条，合计 49 条。逐项映射和优先顺序见 [ToDo 顶部速览](WORKFLOW-TODO.md#距离-10-还差多少2026-10-25-复核)。

首轮复核为 12 组、58 条（原清单余 50 条，另补 8 条正式版门槛）；0.22.0、0.23.0 各完成一条，新增详细颜色后由 0.25.0 完成，0.24.0、0.26.0 各完成一条，0.28.0 完成日语读音整组六条后为 48 条。2026-10-25 新增 6.8 歌名／歌手，增至当前 49 条。公开样本、受控文字和 MV 旧识别副本验证了相应操作路径，正式歌曲人工精度及完整成品仍在第 12 工作包。

这些详细条目共属于上述 12 个工作包。一个包可能需要多个版本，数个紧密相关条目也可能在同一功能版本验收，不能据此承诺“再做 12 版就完成”。0.27.0 完成整体校轴后明确选择重算内部的衔接、当前源码完整回归及正常／150% 独立包验收，属于 4.7、8.5 的子项，不单独减少 54 条；之后推进读音歧义、疑点、样式与输出；真实参考和可恢复性随功能一起验证，最后经过候选版和新手实测才定 1.0。

已有整首歌声对齐只能生成待审核候选；正式 MV 当前仍有保留初稿的句子，没有整首人工时间金标准或已定稿成片。公开 PJS 样本的局部误差不是整首歌曲准确率。真实服务、模拟响应、本地推理和人工验收分别列证据。

2026-10-25 迭代调整：0.28.0 作为完整日语读音校对版本，同时完成 ToDo 4.1–4.5、4.8 六条。0.29.0 计划一起推进 4.6–4.7、第 5 组和 6.8 共八条，当前仅有早期后端检查，不作为完整功能或独立包验收。之后也按完整阶段组织多项目标，不再每版只做一到两条；开发中的项目不提前减数。

## 1.0 的放行标准

- 新手独立跑通完整工作流，卡点修正后复测；不以自动化代替真人使用。
- 正式 MV 能交付继续编辑的工程、ASS／字体、样片、整首成片和中文演示，原始片源保持。
- 人工校准、读音、确认与锁定在自动重算、换源、保存重开、取消和恢复后保持；错误操作可撤销。
- 运行包在无开发环境的 Windows 上通过本地工作流与受支持的联网流程；已知限制明示，未确认结果不冒充完成。
- 许可、隐私和阻断问题已核对；GitHub 版本标签、源码、运行包和验收指纹一致，旧发行版保留。

## 正式版之后再考虑

macOS／Linux、团队协作、云端工程同步、插件市场、复杂演出特效脚本、更多语种与商业可用模型均不作为本次 1.0 的前提。当前模型非商业许可必须明确；本次“正式版”不代表商用授权。
