复核日期：2026-10-29。目标为个人非商业用途的 Windows 1.0。当前已交付0.30，GitHub标签、四份附件的大小／SHA256及匿名下载已核验；0.31第7组已通过完整源码、开发版与两档独立包的本地功能门槛，归档及公开交付另行核对。已有功能与历史证据见各版验收，尚未验证的正式歌曲、真人新手和干净Windows场景继续保留待办；GitHub交付以各版发布回执和远端资产核验为准。

2026-10-29按用户更新的目标调整顺序：先完成未实现功能，性能优化留到最后，并提供可选入口。0.30按6.1–6.6六条功能交付；11.2继续待办，原250ms／500ms等门槛与失败记录保持。功能验收不冒充性能整轮通过，完整1.0仍须完成最终性能、真人新手、正式歌曲与干净Windows验收。

这些详细条目共属于上述 12 个工作包。一个包可能需要多个版本，数个紧密相关条目也可能在同一功能版本验收，不能据此承诺“再做 12 版就完成”。0.27.0 完成整体校轴后明确选择重算内部的衔接、当前源码完整回归及正常／150% 独立包验收，属于 4.7、8.5 的子项，不单独减少 54 条；之后推进读音歧义、疑点、样式与输出；真实参考和可恢复性随功能一起验证，最后经过候选版和新手实测才定 1.0。

已有整首歌声对齐只能生成待审核候选；正式 MV 当前仍有保留初稿的句子，没有整首人工时间金标准或已定稿成片。公开 PJS 样本的局部误差不是整首歌曲准确率。真实服务、模拟响应、本地推理和人工验收分别列证据。

## 1.0 的放行标准

- 新手独立跑通完整工作流，卡点修正后复测；不以自动化代替真人使用。
- 正式 MV 能交付继续编辑的工程、ASS／字体、样片、整首成片和中文演示，原始片源保持。
- 人工校准、读音、确认与锁定在自动重算、换源、保存重开、取消和恢复后保持；错误操作可撤销。
- 运行包在无开发环境的 Windows 上通过本地工作流与受支持的联网流程；已知限制明示，未确认结果不冒充完成。
- 许可、隐私和阻断问题已核对；GitHub 版本标签、源码、运行包和验收指纹一致，旧发行版保留。

## 正式版之后再考虑

macOS／Linux、团队协作、云端工程同步、插件市场、复杂演出特效脚本、更多语种与商业可用模型均不作为本次 1.0 的前提。当前模型非商业许可必须明确；本次“正式版”不代表商用授权。
