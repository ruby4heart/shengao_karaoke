# 声稿 0.20.0：可恢复的整首歌声初稿

完成完整待办第 3 组第一项，将已有转录、原歌词匹配、读音建议、文字对齐、实际歌声音节和审核串为六阶段流程。未选阶段明确跳过，旧五阶段检查点仍可恢复。本版使用真实本地 TIFA，不将均分音节冒充演唱识别；模型限个人非商业使用，用户已明确选择该用途。

## 使用与恢复

导入媒体和正确原歌词，点“按步骤生成初稿…”。已有对应转录可以复用，也可选择 ElevenLabs／Microsoft AI 联网识别，另外选 DeepSeek 读音或 ElevenLabs 文字对齐。选择转录时默认推荐本地歌声音节；离线等分范围不默认启用，先核对实际唱段。开始前汇总上传内容和付费步骤，检查本地模型与音轨，缺少本地资源不会先花费云端额度。

选择当前原声或已有对应人声。整首解码一次，一批歌词只加载一次模型；每句结束就验证音素、边界和输入指纹，先原子保存数值结果，再更新流程检查点。取消等待真实解释器及后代退出、临时文件释放，已完成句子保留。继续只补缺失句子，已完成付费阶段直接复用；状态不明的联网阶段仍由用户核对服务记录后决定重试。

粗略句首句尾可按声音微调；额外分析范围受邻句限制，不覆盖已有重叠。保护已确认、锁定及含人工时间的整行，保留确认过的特殊读音、手工分词、原文、译文和罗马音。修改无关译文不使数值声学缓存失效，但新建议始终按当前输入重建；旧建议采用时另核对完整行快照。原 ASS 采用新轴时明确说明排版切换，原始 ASS 保留。

审核显示每行“歌声候选／需手工／尚未处理”与原因，音节对照默认收起以保留表格空间，可展开逐音试听。存疑位置、缺少读音、无声或无效音素不强行生成声学边界。点“先手工修这一句”先将余下建议存入任务记录，再进入同一句统一编辑区；恢复建议不会覆盖新的人工修改。采用后仍需确认时间，读音确认保持，可保存重开和一步撤销。

## 实测与限制

公开 PJS056 演唱样本拆为三句，共 37 个摩拉，无人工固定时间，实际模型一批推理；另加一行故意无效的读音测试，验证失败与成功共存。开发版及正常／150% 独立包自检执行真实推理、部分审核、保存重开、撤销、检查点复用与人工交接。逐音起止误差记录在各运行时 `staged-acoustic-reference.json`，参考音频和人工音素标签附完整来源与 CC BY-SA 4.0。单个公开样本、未知训练重合，不能推广为整首或其他歌曲准确率。

另以真实模型执行取消后续算，验证至少一句完成后取消、复用该句并补齐余句；续算时增加人工译文，验证缓存复用与新译文同时保持。专项进程测试复现 Windows 虚拟环境先派生实际解释器的情况，检查关闭主任务、取消模型和临时日志句柄释放。模型拥有独立私有 Windows Job，加载前加入，不依靠只杀启动器来清理。

用户指定的 Emerald 正式 MV 使用原文件和已核验的人声轨执行整首本地处理，原媒体 SHA256 保持 `1972808f0caddffdc5d447d3204469e8fe23ff94d27d1861d3523c6cd63b4ac8`。35 句文字取自既有 ASS；旧转录没有媒体指纹，只用作明确标记为未验证的粗范围，重新按原词匹配，不伪造当前片源转录或人工依据。实际生成数量、失败原因、耗时和文件指纹保存在 `formal-song/report.json`，读音与边界均未人工确认。这是整首推理与保护验证，尚不是完成的歌词字幕或 MV 精度测量。

完整发行要求当前源码全量回归，开发版及正常／150% 独立包自检，12 组原版时间轴逐像素零差异，PE 依赖、运行包与源码 ZIP 内容审计。最终计数、截图和哈希以 `build/desktop-final-audit-v020.json`、`build/v020-evidence` 与 `dist/SHA256SUMS-0.20.0.txt` 为准。工程格式仍为 7，读取 1–7；真实 0.18.0 原检查点兼容回归保留。

没有使用 Computer Use、用户密钥或真实付费 API。DeepSeek 和云端转录的流程保护通过模拟服务验证，不能据此声称云端歌曲效果已测。读音歧义、真实休止自动判断、错段检测、集中疑点、正式歌曲成品与真人新手验收继续按待办推进。
