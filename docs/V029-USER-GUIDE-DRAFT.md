# 0.29 新功能使用索引

开发使用稿已合入 [主教程](DESKTOP-USER-GUIDE.md)，运行包内的“使用说明.md”与两份“快速开始.txt”同步。

- 主编辑区细听：上下文、慢放、循环、增强与原声对照、恢复普通播放。
- 音节拆合：先预览，保护固定点、邻音和文字，再采用与撤销。
- 集中疑点：筛选、定位、试听、并排比较、采用／手改／保留／暂缓；进度与人工确认分开。
- 左上角歌名／歌手：文字、字体、配色、安全区、时段及实际预览，ASS 与成片共用。
