## 时间轴

- `build/desktop-tests.xml`：150 项通过、0 失败、0 跳过；含 18 组原版完整 RGB 底图对照，覆盖不同采样率、质量、曲线、增益、缩放和选区配色。
- `tmp/timeline-full-pixels/report.json`、`tmp/timeline-full-pixels-dpi150/report.json`：普通与 150% 各 6 组完整窗口图像对照，不同像素数全部为 **0**。原版绘图体与原版音频渲染作为比较对象，纯场景适配器共用；交互另由 Qt 事件测试验证。
- `desktop/native/aegisub/UPSTREAM-TIMELINE-AUDIT.json` 为用户原始源码审计，`TIMELINE-SOURCES.json` 为提取记录。

像素证据对应本机 Windows 的相同字体、输入和参数，不推断不同系统字体下也相同。

## 独立运行包

- `build/desktop-package-test.log` 与 `build/desktop-package-dpi150-test.log`：普通／150% 各 30 个验收点通过。PATH 只有运行包和 Windows System32，无开发 Python 或 Aegisub。截图实际尺寸分别为 1460×940 与 2190×1410。
- 包含真实视频帧、播放、慢放、校准撤销重做、五页、小窗口、可携带字体、保存重开、ASS 工程、独立后台、真实试压、真实全片 MP4 和恢复文件。
- `build/desktop-dependencies.json`：187 个 exe / DLL / pyd 导入／导出检查通过。common-controls v6 按 exe 清单解析到 WinSxS；Qt 使用系统 ICU。
- `tmp/pitch-availability.json`：真实媒体加载后音高补偿为 `Available`，且已启用。

## 长音频

`tmp/desktop-audio-stress/report.json`：一小时、48 kHz、345,600,000 字节合成磁盘 PCM，连续 90 次频谱／波形渲染通过。单次中位数约 0.64 ms，95 分位约 6.46 ms；工作集约 30.8 → 49.5 MiB。频谱缓存上限 128 MiB，测试后删除合成 PCM。本机合成数据不代表所有机器或压制任务的耗时。

## 验证边界与新鲜度

云端 API 使用模拟响应验证协议、错误、取消、结果审核与保护逻辑；没有读取用户真实密钥或消耗付费额度。真实账号的服务可用性与额度由用户配置后确认。所有测试使用隔离目录及合成素材，未使用 Computer Use，也未操作用户桌面。

构建前后、完整回归与完整图像对照均保存源码及原生模块哈希，发行脚本拒绝过期证据。运行包文件与清单逐项相符，无额外文件。源码与便携 ZIP 由同一发行流程产生并验证 CRC、重复条目和 SHA256。
