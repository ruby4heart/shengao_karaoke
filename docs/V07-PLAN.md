# 0.7 易用性要求

- 首次使用无需理解专业术语：清楚显示当前缺少的资料、下一步及入口，提供可随时打开的快速指南和不联网示例。
- 导入页集中添加媒体、粘贴歌词和制作方式，解释联网与离线；次要入口折叠。校轴、注音、交付均有目的说明和相关提示。
- 停顿处理可选保留、并入前一音节或后一音节；列出时间、时长和相邻文字，允许逐项勾选、阈值筛选、试听、取消、应用和撤销。覆盖词间及词内假名音节；首尾空白另选，锁定内容跳过并说明。
- 合并保持整行起止、原歌词、读音、样式和未选停顿；修改后取消时间确认。原生打 K、可编辑 ASS、成品导出均使用实际更新后的时间，避免仅隐藏空段。
- 草稿在预览／导出前统一保存；新 UI 在普通、窄窗口和首次空工程下验收。原始 Aegisub 和旧发行版本保留，不使用 Computer Use 或真实付费 API。
- 提供 0.7.0 独立运行包、对应源码、上手说明与验收证据。
