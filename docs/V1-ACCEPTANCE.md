# 第一版验收记录

目标：独立的 Windows 日语卡拉 OK 桌面软件，复用提供的 Aegisub 3.5.0 源码。

以下项目由构建、隔离接口测试、已完成的窗口实操和真实原生内部集成验收共同验证。按用户后续要求，后半程不再使用 Computer Use，直接调用同一原生导入、编辑、审核和渲染服务。云端账户权限及真实演唱识别准确度不属于模拟测试可以证明的内容，尚无真实付费服务成功记录。

## 第一版限制

- 真实 ElevenLabs、MAI、DeepSeek 服务未使用付费账户实测；资源权限、配额及实际歌曲效果需配置账户后验证。
- 时间初稿、均分的假名拆分和特殊唱法都需要试听；DeepSeek 不产生声学时间。
- 0.5×／0.75× 试听会变调。
- 成品 ASS 默认 1920×1080；字体取自本机，跨电脑可能需要匹配字体。
- 修改歌词后需手动刷新注音成品预览。SRT／TXT 不保留逐音节高亮和假名布局。
