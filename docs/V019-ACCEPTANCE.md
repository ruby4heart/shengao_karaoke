# 声稿 0.19.0：本地歌声音节对齐

对应完整待办第 3 组第四项。TIFA-1.0-ST 使用正确假名约束实际音频，给出辅音／元音边界并合成为演唱音节；不再以时间均分作为这项功能的结果。仅在本机执行，无需 API 密钥。代码 MIT，模型 CC BY-NC-SA 4.0；本次用户明确选择个人非商业使用，完整模型许可与原作者资料随包保留。

## 使用与保护

在“本句编辑”先填写实际假名，用“整句范围”圈住本句，再点“按本句原声／人声重算音节”。已有对应人声时使用并校验该音轨，否则使用当前视频原声。当前范围须在 0.1–60 秒内，整句头尾保持。读音可能来自词典或人工输入；强制对齐并不能证明这个读音本身正确。

人工音节、锁定词组、人工词组头尾作为固定边界；只推理其间未固定部分。整句已确认或锁定时拒绝重算。原歌词、原有分词、假名写法、罗马音、译文及读音确认保持。平假名、片假名、拗音、促音和长音经明确映射输入官方音素字典，不从转录空格重新切歌词。

结果先审核：逐音节比较旧值和建议，选择音节可带前后音试听。采用后仍需人工确认时间，可一步撤销；保存重开保留声音依据、输入音轨指纹及固定位置。后台期间的人工修改会使旧建议拒绝写入，结果仍可从任务记录恢复。原 ASS 保留模式采用新音节轴时会明确说明改用声稿排版，原始 ASS 不删除。

音素缺失、无效边界或几乎无声的区间保留原值；整项没有可用结果时不写入工程。极短、过长、较长间隔及相同音连续的内部分界列为试听疑点。模型自己的 agreement 不作为准确率显示。旧“连续划音”的固定时长规则不填平声学候选产生的休止；未实现整首自动判断真实休止。

本地缓存绑定完整源、输入音轨、模型、假名、原时间与人工固定边界，校验结果内容后复用。临时音频及推理在独立进程中运行，取消会终止子进程；可以继续普通校对，不阻塞 UI。失败／取消保留工程。共享独立 CPU 引擎承载 Demucs 与 TIFA，运行包无需用户安装 Python。

## 实际声音证据

- 官方 TIFA 源码固定为 `d246be1cc2e202613213ca60a4e5d35e71a2fb6a`，模型 SHA256 为 `8d9bf896da1827f36bf135f80c7ab1fc4f3c1d48f328818b8402c9527c0f014b`；运行时同时校验配置、词表和日语字典。
- 公开 PJS056 演唱样本与 UtaUtaUtau 人工音素标签：原始音频及标签保留，以人工标签合成摩拉参考。开发版实际工作流固定 1 个音节，评估其余 36 个音节，起点平均偏差约 7.7 ms、最大约 66.1 ms。统计不包含固定音节；这是一个公开样本，训练重合未知，不能推广为整首、其他歌手或 MV 的准确率。运行包自检也实际执行此样本，具体结果以各自 `acoustic-human-reference.json` 为准。
- 用户指定 Emerald MV 第一行在现有人声辅助中实际推理，8–18 秒范围得到 20 个不同长度的演唱音节，候选约从 8.37 秒至 17.18 秒，中间保留约 540 ms 的间隔。该 MV 尚无人工金标准，因此只记录可审查候选，不声称这些边界已经人工确认。
- 另行比较了 SHIRO v1/v2 与 TIFA 对同一公开音素参考的结果；本次选择 TIFA。SHIRO 不随本版分发，也不把单样本模型比较当成通用性能排名。
