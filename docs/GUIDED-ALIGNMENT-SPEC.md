# 人工位置引导局部重算

0.26.0 对应 ToDo 3.9。用户提供音节的起点或终点，程序在固定点划开的区间内调用本地 TIFA。默认只处理首尾给定位置之间；也可明确选择本句全部未固定部分。原文、分词、假名、罗马音、译文、整句演唱与显示范围保持。人工整音节、人工词组外缘和锁定词组仍为约束，不复制其他唱段的时间。

## 数据与保护

`Highlight.fixed_edges` 是 `start`／`end` 的无重复列表，引用该音节当前相应边界；空列表不写入旧式字典，兼容已有任务签名。只固定起点时，终点仍为候选。工程格式 11 读取 1–11；0.25.0 及更旧版本拒绝 11。旧格式不得夹带非空固定点。工程与声稿 ASS 元数据保存这些约束；通用字幕格式无法携带的内容仍以工程保存为准。

固定点按词组、音节、起止顺序排序。位置必须在本句内，顺序不得倒退，不得移动已有人工音节或锁定边界。默认范围外的音节数据保持；给定点与范围外邻音冲突时拒绝，不偷偷挤动它们。临时内插只用于准备可用分析范围，不作为已识别演唱轴。只有实际模型结果通过验证后才能生成建议。

模型在各子区间内返回音素与摩拉边界；人工约束对相应起止点具有优先级。保留原始模型音素范围，时间来源分别记录模型参考与采用后边界；不改写音素证据来伪造模型命中。人工固定处的零误差不进入模型准确率统计。已有固定点在后续本句重算中仍生效；无明确人工替换的整首匹配、初稿、读音分析及空隙整理保护它们。

## 界面与恢复

校准页的“固定位置后局部重算…”提供原版频谱／波形、邻句参照、兼容的选择与试听操作、播放滑条、毫秒输入和固定点表。绿色虚线显示位置。时间轴持有独立的只读 PCM 映射和原生绘图实例，关闭不销毁主时间轴资源。小窗口正文滚动，生成、取消及人工入口固定在底部。

定位草稿逐次原子保存，绑定工程标识、素材记录及完整本句快照；任务请求保留完整规划、行快照和确认状态。取消不改工程。模型失败时本次整句不采用，原轴保持，定位仍可继续或回主编辑区手改。保存失败时禁止开始并明确说明；任务请求无法落盘时不启动模型。旧定位与当前工程、素材或本句不符时拒绝恢复，保留旧记录。

结果先审核，采用验证原始规划与固定点、范围外音节、人工内容和迟到修改。缺少原始规划时拒绝引导建议。暂存审核、自动恢复及任务记录携带规划，采用只产生一次撤销。解除所选音节固定点不移动时间或丢失选择，可撤销；明确人工编辑或整体校轴按既有操作规则执行，不因固定标记阻止用户修改自己的时间。

## 验证边界

结构与真实 Qt 回归覆盖单边、双边、范围外保护、旧字典兼容、异常约束、失败、保存、重开、暂存、迟到编辑和撤销。公开 PJS056 受控草稿提供两个人工位置，仅中间 19 摩拉经实际 TIFA 生成；其余部分保留参考衍生初稿。记录未固定起点误差，单一样本、训练重叠未知，不能代表一般歌曲或正式 MV 精度。正常／150% 独立包、全量测试与原版像素对照的最终结果列在本版验收记录，通过后才完成 ToDo 3.9。
