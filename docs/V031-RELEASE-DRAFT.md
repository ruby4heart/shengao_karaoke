五步流程根据同一份工程状态显示下一步。已有确认歌词可直接继续样式；访问页面不等于完成校对，保存作品、确认时间、确认读音和输出当前成片分别记录。样片与整片完成状态分开，修改后不把旧输出当作当前成品。

打轴快捷键设置可搜索、修改、增加备选、恢复原版默认和导入／导出。保留Aegisub 3.5.0的Audio与可选Medusa Always上下文，检查冲突并区分主／小键盘。导入先审核，保存成功后才启用；写盘失败、取消或坏文件保留旧配置。默认保护文字、时间、表格及输入法，旧版明确启用的Always行为迁移保持，可主动启用输入保护。未支持的Aegisub其他命令不会偷偷执行。

跟唱打点是可选手工草稿：现有音节和原播放器时间基准，逐音起止或明确选择的连续分界，支持暂停、续录、停止回句首、退回、重录、新旧比较和一次撤销。固定边界及词组原有边缘留白保持，人工时间须明确允许替换，录制期间的歌词／素材变化拒绝旧草稿覆盖。应用不自动确认时间，不能将打点当作AI或物理音频延迟测量。

本机GPU缩帧可以关闭并回退常规预览；普通本地任务并行数可选系统默认、1、2或4，不冒称模型或FFmpeg内部线程限制。原片／轻量预览、原唱／伴奏及原声／人声保持独立。它们是可选功能，最终性能门槛仍由ToDo11.2验收。
