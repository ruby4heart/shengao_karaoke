声稿 Karaoke Studio 0.26.0

完整解压后运行 shengao-karaoke.exe，无需 Python、FFmpeg 或 Aegisub。
先用软件内的离线练习熟悉操作。详细中文教程见“使用说明.md”。

1. 拖入视频或音频，粘贴每行一句的原歌词。没有歌词可先识别，再核对文字。
2. 点“按步骤生成初稿…”。默认离线；联网识别或 DeepSeek 需配置密钥并使用服务额度，结果先审核。
   重复副歌可先确认一句的分词、读音和时间，再点“复用已校对副歌…”。
   只复用文字分词和读音，按目标段歌声重新生成时间；先审核，人工内容保留。
   可只复用读音，时间仍待校准；失败或取消后从任务记录继续，不使用 API 额度。
3. 逐句改分词、假名、罗马音与音节时间。歌声候选也需试听；“来源／提示”解释时间依据。
4. 整段错位用整体提前／延后或渐进漂移工具；“检查空白…”按声音提出候选，试听后采用，不只按时长填平。
5. 读音与时间分别确认。保留上一句参照，疑难处可慢放、循环或切到人声辅助。
6. 选择日式双行注音模板，先压制样片，检查后导出 ASS 或 MP4。
   “颜色与演唱状态…”可按待唱、唱中、唱完分别改文字、描边、阴影和底板。
   先选范围，再用预设或细调；取消保持，采用后可一步撤销，时间轴不变。
   工程格式升级为 11，0.25.0 及更旧程序不可读取，请为旧作品另存副本。
7. Ctrl+S 保存 .sgproj；人声资源与工程同名 .assets 目录一起携带。
8. 可添加原唱／伴奏两个视频源，一键切换后分别输出，共用同一份字幕。

视频滚轮缩放，双击适合窗口。音频可切波形／频谱，保留 Aegisub 音频键位。
联网等待超时不会自动重提付费请求，先检查任务与服务记录。
审核的“整首顺序检查”可试听漏句、重复段、错段和未分配转录候选。
“定位到主界面校对”先暂存建议；“限定正确时段重匹配”只复用已有转录改这一句。
文字候选不能证明实际缺唱或多唱，原歌词与人工内容保持，采用可撤销。
本版工程格式 11，读取 1–11；0.25.0 及更旧程序拒绝第 11 版，请另存副本。
本地 TIFA 模型限个人非商业用途，许可随包提供。

用正确位置引导局部重算（0.26.0）
   确认假名并补全音节后，点“固定位置后局部重算…”。
   选音节及起点／终点，试听、中键定位或拖播放滑条，
   点“读取当前播放位置”再“加入／更新固定位置”，也可输入毫秒。
   至少给两个点，默认只重算首尾点之间；范围外音节与人工内容保持。
   绿色虚线表示固定点；只固定所选一端，另一端仍需试听。
   本机生成后先比较并审核，勾选采用才写入，可一步撤销。
   草稿自动保存，关闭不改原轴；失败、取消保持整句原时间。
   任务记录可继续定位，或“返回本句手工校对”。素材或歌词变更时拒绝旧定位。
   固定点随工程与声稿 ASS 保存，后续重算继续遵守。
   选该音节点“取消所选音节的固定点”，时间不动，可撤销。
   工程格式 11，读取 1–11；0.25.0 及更早版本不能读取，请另存副本。
