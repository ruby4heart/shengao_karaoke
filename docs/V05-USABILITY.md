# 0.5 分词、匹配与易用性改进

## 0.5.1 分词条修复

识别产生的短停顿、连续空白 `\k` 标签原先也各占一个分词格，导致两条分隔线夹出空段。现在显示层按实际歌词建立分组，空白时段和只有空格的片段不再生成额外边界，原歌词空格及全部时序保持不变；包括长停顿和人工时间，不通过压缩时间消除格子。已有工程直接打开即可生效，ASS 导出仍保留必要的空白停顿标签。

点击显示边界会一次合并真实相邻词及中间全部空段，保留总时长、文字和样式标签。正常词内拆分使用原始音节索引，取消、提交和撤销沿用原生流程。词首、词尾、只有空格的部分不允许误拆出空音节，纯空白行不显示分隔线。

## 原歌词是唯一的文字来源

先粘贴或导入原歌词，再转录并匹配。比较时会忽略识别多出的空格和分行，输出始终采用原歌词的文字、空格、标点与分行。分词也重新分析原文，不沿用 ASR 给出的词边界。

例如原文 `今日も、歌う！`，识别为 `今 日 も 歌 う` 或 `きょう も うたう` 时，结果仍是原文；词组为 `今日`、`も、`、`歌う！`。标点和原文空格附着到相邻词组，字符不会丢失或新增。

粘贴歌词也会保留行首、行尾空格。可选择替换已有识别初稿或追加；替换会重建粗轴和注音，保留打开的媒体，并支持撤销。有人工确认、锁定或手调内容时默认选择追加，避免无意替换。

## 分词与演唱音节

- 内置 Janome 0.5.0 与 IPADIC，离线按词组生成假名和罗马音，不需要密钥。库与词典的来源、授权及对应源码一起提供。
- “校轴”页选择选中行或全部未保护歌词，点击“本地按原歌词分词＋假名”。后台完成后先审核再应用。
- 点击“按读音拆演唱音节”，会保持汉字词组，并将 `今日 / きょう` 拆成 `きょ｜う`。不会为了音节数将汉字切成错误读音；促音、长音、拨音单独处理，小假名附着前音。
- 新生成的边界属于估算，需要试听。已有词组时间、停顿、相同读音的人工音节边界保持；锁定行、锁定词组和已人工确认的行跳过。
- “注音”表格可直接选词拆分或与下一词合并。拆分须保持原字和空格不变；合并保留已有音节与静音间隔。操作可以撤销，正在编辑的译文也会先保存。
- 本地词典不能判断歌曲中的特殊唱法。可手改假名，或用 DeepSeek 修正读音和翻译；修正读音时重新生成需要变化的音节，保留读音未变的人工边界。

## 匹配与修正

- 在原文字形匹配之外增加词典读音辅助，改善汉字／假名写法不同导致的漏配；相似度仍是文字对应程度，不是声学置信度。
- 已人工确认或锁定的歌词时间作为附近段落的定位锚点，避免前后副歌随整首编辑路径漂移。
- 有重复副歌的结果提供候选位置。审核窗口显示时间、分数、原词和词组读音，可以试听、停止、切换候选、仅勾选可用行或取消勾选。
- 切换候选只改变待审核建议；点击确定才写入工程，取消保持原工程。低可信结果默认不勾选，已保护或处理中被修改的行不会覆盖。
- 没有合适候选时，用“复用已有转录 · 本地匹配”，选择已有记录，默认只处理选中歌词，并手填要搜索的开始 / 结束秒数；可以先试听范围，再本地重做，不重新上传音频。

## 验证范围与限制

后台使用原文和 ASR 空格不同、汉字／假名变化、重复副歌、已确认锚点、遗漏歌词、特殊读音、静音及锁定结果等样例。实际主程序通过 wxProcess 调用词典后台，应用 / 撤销词组编辑，并在真实审核窗口中测试候选选择、试听、停止、取消和确认，同时回归四阶段界面、窗口边框、保存和字幕导出。

完整运行包会在清理开发 PATH、Python 设置和用户密钥的环境中检验离线词典、读音辅助匹配、导出和安装。所有验收使用合成媒体与模拟接口，没有上传用户歌曲、没有真实付费 API 调用，也未使用 Computer Use。

## 发行

运行 `dist/ShengaoKaraoke-0.5.1-final-win64/shengao-karaoke.exe`；已有加密密钥设置继续沿用。旧版程序、工程和原始 Aegisub 源码保留。构建方法见 BUILD.md，操作见 使用说明.md。

0.5.1 验证包含 226 个原生检查点、46 项后台测试、402 项 C++ 测试及 LuaJIT。新增真实分词条的八词七边界、1500 ms 长停顿、一次合并与撤销、空段后的日文词内点击、纯空白行，以及合并时同一位置多项样式保留等回归。完整运行包另在隔离环境下检验词典、读音辅助匹配、四种导出和安装；图像证据来自程序自身渲染，分词条修复见 images/karaoke-single-boundaries.png。
