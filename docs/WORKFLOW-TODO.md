## 产品目标与最终工作流

用户无需了解 Aegisub 或 ASS 标签，能够独立完成：

拖入视频 → 准备并确认原歌词 → 自动生成初稿 → 修正整体位置 → 逐句处理读音与音节疑点 → 选择日式双行注音样式 → 试压样片 → 导出 ASS 或成片 → 保存后继续编辑。

AI 承担初稿与候选生成；程序承担格式、渲染、保存、校验与压制；人工决定歧义、特殊唱法、演出效果及最终定稿。不能把时长均分或字符时间戳标成已经准确识别的演唱音节。

## 执行顺序与交付标准

1. 统一校轴范围、整体偏移与渐进漂移校正；完成整首／多句／本句的真实 Qt 操作和撤销验证。
2. 整合本句编辑区、相邻句衔接、分词与注音；先打通无需云端也能完成的人工工作流。
3. 增加人声辅助、音节对齐、读音候选、局部重算与集中疑点；用正式歌曲测量实际改进。
4. 完善双行留屏、字体、预览性能、导出和恢复；修正所有操作说明与实现差异。
5. 完成正式歌曲全流程、新手独立使用验收及运行包检查，交付新版本、源码、演示工程、成片与使用说明。

完成标准是新手能够修正整首错位、处理局部疑点并独立导出成片，同时人工成果可保留、撤销和恢复。单个页面、单项功能、合成示例或测试数量不单独代表全部完成。
