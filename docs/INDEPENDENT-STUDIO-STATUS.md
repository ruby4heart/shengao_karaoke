# 独立工作台 0.8.0 状态

完整目标见 `INDEPENDENT-STUDIO-PLAN.md`，逐项验收见 `DESKTOP-ACCEPTANCE.md`。本轮为独立 Qt 工作台，不是在旧 Aegisub 主窗口上增加面板。

## 实现

- 独立窗口、原生标题栏、五步流程、自有工程与统一撤销；原文、词组、假名、罗马音、演唱音节、翻译、读音和时间确认分别保存。
- 复用后台转录、局部匹配、分词和注音；ElevenLabs、Microsoft AI、DeepSeek 设置由本机 DPAPI 加密。结果审核、候选试听、人工数据保护、任务取消及恢复已接入。
- 播放、循环、保留音高慢放、词组／音节／整句校准、批量边界、关键帧与邻句吸附、停顿保留与双向合并。
- 原版 FFT / HSL / 频谱和两种波形算法；`shengao-view.dll` 保留原版刻度、文字、标记、手柄及滚动条的离屏绘图。wx 只提供 wxMemoryDC / wxGCDC，不创建 wx 窗口；不启动 Aegisub，不链接 FrameMain 或 agi::Context。
- 统一 libass 实时预览与 ASS 生成；内置 Noto 字体、本地字体集合、整首字符覆盖、样式卡片、排版检查、字体资源携带及复杂 ASS 保留。
- 内置 FFmpeg 的 CPU / 可选硬件 H.264 + AAC、12 秒试压及全片 MP4；进度、预计时间、取消及原子发布。旧工程、ASS、SRT、LRC 可导入。

## 当前证据

- 最终源码完整回归：150 项通过，0 失败、0 跳过。
- 整条时间轴：普通与 150% 缩放各 6 组，原版与新窗口 RGB 全像素相同；底图另有 18 组独立原版对照。
- 最终运行包：无开发 Python / Aegisub 的隔离 PATH，普通与 150% 各 30 个自身验收点通过，包含真实播放、独立后台、保存重开、试压和全片压制。
- 187 个 PE 二进制的导入／导出依赖通过；一小时 PCM 缓存连续 90 次可见区渲染通过。
- 构建、测试、图像对照与当前源码哈希一致；包内 805 个文件与清单一致，无额外文件。

测试使用合成素材、离线任务和模拟云端响应。没有使用用户真实密钥或付费额度，没有操作用户桌面，也没有使用 Computer Use。

## 已解决的环境问题

构建曾因自动审批账号用量限制未执行，恢复后已重新获批并完成。受限测试进程出现过 QProcess 无结果和媒体等待的无效句柄异常；正式证据来自之后获批的完整回归及独立运行包验收。

Qt 的系统 ICU 同名冲突、窗口模式后台 stdin、低采样率缓存关闭、字体集合次字体选择、窄窗口字体卡片溢出及旧 ASS 同时行迁移问题均已修复并验证。
