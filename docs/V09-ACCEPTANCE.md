# 声稿 0.9.0：易用性、界面和缺陷验收

日期：2026-10-17。用户目标见 `V09-PLAN.md`。本轮在独立 Qt 工作台上改进实际制作流程，保留原版时间轴和旧版本。

## 新功能与界面

| 范围 | 结果与证据 |
| --- | --- |
| 现代、易懂的界面 | 统一浅色界面、两行步骤导航、状态层级、清晰播放按钮、欢迎页和最近作品。普通／150% 自身截图及 960×680 小窗口检查通过。 |
| 主要操作清楚可见 | 下一步随素材、初稿和确认状态变化；单句修正工具可展开；时间与读音分开页签；导出页固定样片／成品操作，导航不裁切且无横向溢出。 |

## 修复的问题

- 正在修改读音时切句／切页／保存／关闭，先提交当前编辑；无效读音阻止切句，原文保持不变。
- 放弃当前修改后打开损坏工程，打开失败不会把旧工程错误标记为“已保存”，恢复文件仍保留。
- 建议只采用一部分时，其余行继续待审核；应用失败、原文不符或锁定时不丢掉结果。明确放弃干净工程的建议后，不会在下次启动恢复已放弃内容。
- 旧版本仅导出视频素材，音频导出失败；现在提供纯色背景视频，处理区间和时长有边界检查。
- 试听区间与跳转超出时长时限制到有效范围；播放中切换循环即时生效；变速时重置播放插值基准。
- 切换素材立即清除旧波形与旧画面，防止依据上一份素材校轴。
- 退出后后台任务完成时，不再向已销毁的 Qt 信号对象发送消息。
- 修复窄窗口步骤导航被挤住；原文标题在小屏缩减重复信息，时间与导出主要操作保持可见。
- 检查列表注明具体句子，并将读音问题直接定位到读音页、字体问题定位到样式页。
- 同一字体重复注册按文件身份去重。

## 实际验证

- `build/desktop-tests.xml`：**165 项通过，0 失败、0 跳过**。含原有后台与字幕回归、Qt 实际编辑／快捷键／确认／播放、损坏配置与打开失败、部分建议保留，以及真实纯音频 MP4 解码检查。音频视频的背景颜色、画面尺寸、时长与可见字幕均验证。
- `build/desktop-package-test.log`：最终 exe 在仅有运行包和 Windows System32 的 PATH 中，**42 个检查点通过**。
- `build/desktop-package-dpi150-test.log`：相同隔离环境，150% 缩放 **42 个检查点通过**。
- 运行包检查覆盖实际视频帧、播放与慢放、撤销／重做、五页、小窗口导航、固定导出操作、实际预览 A/B、真实保存与最近作品、独立后台、时间／读音确认、视频试压／全片导出、纯音频预览与真实字幕视频、恢复文件。
- `tmp/timeline-full-pixels/report.json` 与 `tmp/timeline-full-pixels-dpi150/report.json`：**12 组完整时间轴 RGB 对照，不同像素数全部为 0**。新 UI 未改变原版频谱、波形、刻度和标记算法。
- `build/desktop-dependencies.json`：**187 个** exe / DLL / pyd 的依赖与导出符号检查通过。
- 构建、完整测试、像素报告保存当前源码哈希，发行门禁拒绝过期证据。运行包 805 个文件；便携和源码 ZIP 经 CRC、重复条目、SHA256 验证。

界面截图见 `docs/images/shengao09-home.png`、`shengao09-calibration.png` 与 `shengao09-export-compact.png`。来源为程序自己的离屏验收实例，没有操作用户桌面。

## 保留与边界

旧 0.8.0、0.7.0 发行包和用户原始 Aegisub 保留。工程格式仍兼容版本 2；媒体类型为新增可选元数据。已有复杂 ASS、字体、手调时间和原歌词保护继续回归。

云端接口采用模拟响应验证，实际后台分词、媒体处理和编码使用真实独立进程。没有读取真实密钥、调用付费服务或使用 Computer Use。
