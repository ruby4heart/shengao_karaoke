# 0.9：更清楚的制作流程与现代界面

用户目标：主动补充实用功能，修复发现的问题，在不损害易用性的前提下，让界面更现代、用语更通俗。原版 Aegisub 时间轴的显示保持不变，继续验证完整像素对照。

## 本轮范围

1. 统一浅色界面、清晰的导航与状态层级；初始欢迎页和最近作品；原生标题栏保留。普通笔记本及 150% 缩放均可使用。
2. 突出当前下一步；生成页将额外修正工具折叠；字幕前后对比、导出后播放与打开目录可直接发现。原有操作仍可访问。
3. 时间输入显示为分／秒／毫秒，兼容既有毫秒数据；可按当前播放位置设置开始或结束。增加下一处待确认，完成整首后给出样式／导出入口。
4. 修复编辑提交与切句／切页／关闭之间的数据保护，搜索过滤时选择不跳错；修复建议应用失败或只应用一部分时未采用结果被清空的问题。
5. 音频素材可生成带纯色背景的字幕 MP4；预览和输出背景一致。修复播放区间越界、播放中切换循环和变速时的位置问题。
6. 最近作品和界面偏好独立存储，损坏配置可恢复默认，不进入工程或密钥配置。保留旧工程兼容与所有旧运行包。
7. 检查完整工作流、实际 Qt 事件、真实压制、普通／150% 布局、原版时间轴像素、独立 exe、依赖及对应源码后交付 0.9.0。

## 验收边界

不修改用户原始 Aegisub，不操作用户桌面，不读取真实密钥或调用收费 API。使用自身离屏实例、合成媒体和模拟响应。新运行包与源码完整交付；不将单个页面截图或只改配色作为完成。
