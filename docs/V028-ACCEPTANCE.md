读音流程实际打开 Qt 窗口和原生审核、试听合成音频、查询固定 IPADIC 条目、读写测试自己的词典、通过可见范围控件更新注音映射、预览／采用／取消与撤销罗马音和译文，并验证固定点、原声学资料、锁定与迟到修改保护。新建议本身不自动联网，时间与日语读音确认分开，译文确认也独立。手写及未知来源旧罗马音保持，已记录自动规则随假名更新；不能静默消除真正人工音节。

实际组合字幕同时包含手工注音范围、罗马音和中文译文，并经过 libass、声稿 ASS 重开及随包 FFmpeg：开发版非空字幕 1128 像素，字幕区域平均 RGB 差约 3.744，阈值掩码差 54 像素；两种缩放独立包按同一门槛逐次验证，具体值在各 `reading-workflow-audit.json`。注音窗口使用实际字幕区域放大，成片字号和时间不变。

工程格式 12 读取 1–12，新增本歌词典、注音对应、罗马音设置／人工覆盖和新词默认；0.27.0 及更旧程序明确拒绝 12。个人词典只在本机，导出仅包含选定词典；验收只写自身目录，不进入私人用户目录。历史任务空选项不增加字段，旧检查点与原版资产保留。

早期源码回归、跨阶段译文保护失败与修复日志会随本地完整证据保存，不能作最终通过凭据。最终未调用真实付费 API、未使用用户密钥或 Computer Use；文字建议是受控模拟，练习音频为合成素材。新增校对测试不证明歌曲读音、真实服务兼容性或一般声学准确率。既有 PJS 单公开样本、未知训练重合，也不代替正式 MV 人工参考、整首成品、干净 Windows 和真人新手验收。

正式版仍余 8 个工作包、48 条主待办及 4 条持续交付要求。Git 提交、版本标签、完整源码、Windows 包、公开验收和指纹须相互核对；只有四个远端资产摘要、大小和公开下载检查完成后才算 GitHub 交付。
