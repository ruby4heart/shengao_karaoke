# 历史 README：0.7.0

仅供历史参考，当前使用与构建请看根目录 README.md 和 DESKTOP-USER-GUIDE.md。

## 已交付的 0.7.0

独立 Windows 日语卡拉 OK 制作软件，基于用户提供的 Aegisub 3.5.0 开发。

0.7 以首次使用为主：中央提示下一步，导入页集中准备素材，新手指南附不联网练习示例。停顿可逐项试听，选择保留、并入前一音节或后一音节，先看时间变化再应用，支持整次撤销。新增专注打轴／放大预览，区分“应用本行修改”和“保存工程”，显示时间确认进度。

0.5 改进分词与匹配：以原歌词为准，忽略识别多出的空格，内置离线日语词典、词组假名与演唱音节拆分，增加读音辅助匹配、可试听的副歌候选、局部重匹配和手动词组拆合。粘贴原歌词可以替换识别初稿或追加，保留原文首尾空格，操作可以撤销。

## 使用

完整解压 dist/ShengaoKaraoke-0.7.0-final-win64 后运行 shengao-karaoke.exe，无需 Python 或另装词典。已有加密 API 设置继续使用，旧版本和原始 Aegisub 目录保留。

1. 添加视频、粘贴原歌词，转录并按原文分词匹配；已有转录可直接本地复用。
2. 审核中试听、选择副歌候选。错位行可指定时间范围局部重匹配，不重新上传。
3. 点击“逐词校对”，拖边界并试听；“停顿 · N处”可逐项保留／合并空段，确认后进入下一行。
4. 点击“二次分析”复核汉字读音，先看转录依据，再试听并勾选应用；注音表格可手改、拆合词组。
5. 保存 ASS / JSON 工程，导出带假名、罗马音、译文及高亮的成品 ASS，另支持 SRT / TXT。

操作见 [使用说明](docs/使用说明.md)，改进与验证见 [0.7 验收范围](docs/V07-USABILITY.md)。

## 0.7.0 历史验证与限制

验收包含空工程启动、下一步和新手指南、停顿保留／双向合并／试听／取消／撤销、真实 ASS 保存重开与后台成品导出、制作视图切换，以及既有分词、读音、窗口和任务回归。程序只在自己的本地测试实例中渲染界面；接口使用模拟 HTTP 和合成音频，未使用 Computer Use、用户密钥或真实付费 API。

匹配得到粗轴，文字分数不是声学置信度；新增演唱音节边界属于估算，需要试听校准。识别文本同为汉字时不能证明实际唱法；DeepSeek 只结合文字上下文，不直接听歌。特殊唱法仍需试听确认。0.5× / 0.75× 试听会变调，成品 ASS 默认 1920×1080。

密钥经标准输入传入配置进程，使用 Windows DPAPI 加密，不进入工程或任务元数据。后台不会自动重复提交付费请求，已有转录可以反复本地复用。

## 源码与构建

native/ 与 scripts/apply-studio.py 是原生改造入口；backend/ 是接口、词典、匹配与导出。vendor/aegisub 保留开发副本和依赖，vendor/python 含 Janome 0.5.0 官方源码归档。授权随运行包与源码包提供。构建见 [BUILD.md](docs/BUILD.md)，对应源码为 dist/ShengaoKaraoke-0.7.0-source.zip。
