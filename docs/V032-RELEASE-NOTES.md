# 声稿0.32：时间轴精修、可靠保存与完整导出

本版合并0.31之后完成、并由用户在 Windows 上验收的内容：第8组保存与恢复、第9组导出整合、时间轴精度前四条，以及正式版门槛中的故障恢复、联网前说明与隐私、许可核对、可选优化回退和首次使用指南。0.31.0只推送了标签，没有单独发布 Release，其内容一并包含在本版。软件整体尚未达到1.0；当前剩余14条主功能／验收待办。

- 时间轴精修：内置歌声模型在句子可自由调整的开头和结尾识别换气与余韵，不再把它们算进第一个或最后一个音节。“检查句尾…”给出收尾类型（被下一句抢拍、拖长音、弱尾音、渐弱／气声）和声音降落、音高结束、下一句开口前三个参考位置，可疑句尾集中列出，可试听、一步采用或撤销。“多方案比对时间…”并列转录时间、文字对齐、内置模型（原声／人声辅助）、另一读音和已确认副歌节奏等方案，标明差异音节；不自动选择，不额外发起付费请求，锁定、确认与人工内容不变。
- 精度测量：用程序自带的 PJS056 公开演唱和人工音素标注测量，初稿范围的句首平均绝对误差由15–24 ms降到8–15 ms；句尾在这份干声语料上整体略有提前（50 ms 内仍为97–100%）。Emerald 正式歌曲的人工参考测量仍待完成。
- 保存与恢复：自动检查点、版本历史、按句比较与恢复，素材移动后可重新定位；各阶段记录输入版本并复用已完成阶段，付费请求超时不自动重复提交；未连接、上传中、服务等待、响应解析和本地处理失败分开说明；可导出去除密钥的诊断报告；重开工程回到上次编辑的句子、音节和播放位置。
- 导出：字幕、样片和整片共用同一份时间与排版；样片范围、分辨率、质量和输出目录明确；批量压制队列可取消并记录每项结果；字体随工程／ASS 携带，缺失时提示；LRC 说明与实现一致，ASS 可编辑往返；失败或取消不会把半成品标为成功。
- 故障恢复与隐私：文件损坏、路径移动、磁盘已满、程序强制退出、压制中断和模型进程失败都有明确说明并保留原文件。每次联网前说明发送到哪家服务、发送音频还是文字、本机保存什么；新增隐私检查，确认工程、诊断、Git 与发行包里没有密钥或私人素材。
- 可选优化：GPU 预览出现任何错误都会自动改用普通画面；关闭 GPU 预览并只用1个后台任务时，完整制作流程仍可使用。
- 许可与首次使用：逐项第三方清单写明来源、许可和固定指纹，明确 TIFA 歌声模型权重的非商业限制；新增“首次使用指南.md”，含默认设置、快捷键和已知限制。
- 兼容性：工程格式仍为14，读取1–14；0.29及更旧程序不能打开第14版工程，请为旧作品另存副本。

验证：发布前在 Windows 上用 `scripts/run-release-freeze.py` 对同一提交一次跑完15步——完整源码回归、构建运行包、全部 DLL 依赖、开发版自检、正常和150%缩放独立包自检、两档原版时间轴逐像素对照、三种窗口检查（正常、150%、关闭可选优化）、故障演练、外部服务本机模拟、完整许可核对、生成并核对发行包、发行包隐私检查。各步报告见附带的验收记录 ZIP。没有使用 Computer Use，没有调用付费接口。

限制：Emerald 正式歌曲完整工程与人工参考、真实云端接口记录、本机性能基线、全新 Windows 环境和真人新手试用仍在 ToDo。当前歌声模型含非商业限制，本版面向个人非商业制作，不代表商业授权。
