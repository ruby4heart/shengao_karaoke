# 声稿 0.14.0：原唱／伴奏一键换源

本版单独交付媒体版本切换；保留 0.13.0 统一校轴及更早发行包。其余完整待办仍待实施，不把换源标成人声分离或自动对齐。

| 行为 | 验证 |
| --- | --- |
| 两个版本共用字幕 | 实际原唱／伴奏往返，锁定、时间确认、读音、音节、原始转录及样式不变；不调用 API |
| 新源后台读取后原子切换 | 读取中保留旧播放器；损坏、丢失、取消、读取期间文件改变不改工程；完成前提交正在输入的有效假名，无效时保留旧源；忙碌状态不显示旧百分比 |
| 暂停仍直接看见新画面 | 静音解帧、恢复播放点与原音量；2 秒后变色的视频确认预览为 2.4 秒画面 |
| 时长与同步 | 差异超过 300ms 或字幕超出新片尾提示；拒绝时无变化，接受后不拉伸歌词 |
| 撤销与保存 | 一次切换一步 Undo／Redo；第 4 版工程保存相对源路径、两版本及当前选择；兼容旧工程 |
| 输出实际使用当前源 | 两段不同颜色、440／880Hz 音轨的合成媒体分别压制，解码成品验证图像与音频频率；默认名称区分版本，任务记录实际源；两个源均禁止作为输出覆盖 |

专项测试在 `desktop/tests/test_media_versions.py`。完整冻结源码回归、正常与 150% 独立运行验收（各 93 项）、原版时间轴 12 场景像素对照、原生依赖与发行完整性审计均为交付门槛，最终结果见 `build/desktop-final-audit-v014.json` 及 `build/v014-evidence`。

测试使用本地合成素材、自有离屏窗口和模拟 API，不读取用户密钥、不调用收费服务、不使用 Computer Use。未以用户正式歌曲验证人声／伴奏同步；两个版本存在剪辑差异时仍须试听。
