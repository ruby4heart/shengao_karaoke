# 0.4 界面与保存文字修正

用户目标：

1. 整体界面需要完整优化，增加美感和明确的分割线。
2. 修复右下角“保存改动”文字显示问题。

## 实现范围

- 深墨色顶栏、统一蓝色主操作、白色三栏面板与明确边框，重新统一字体、留白、文字层级、圆角和分组线。
- 覆盖歌词库、搜索筛选、当前行、视频预览、时间轴、播放区和导入 / 校轴 / 注音 / 交付四个工作阶段。
- 统一绘制主要按钮与步骤页签，包含正常、悬停、按下、焦点和禁用状态，提供键盘操作及辅助功能名称。
- 时间轴默认使用深蓝和青色；原生缩放、波形高度、音量改为带标签的水平控件。按真实内容高度分配预览与波形空间。
- 保存操作独占完整一行，保持“保存改动”四字完整居中。禁用时使用可读的深灰文字，避免系统主题覆盖文字颜色；任务取消、审核、历史记录另成一行。

## 验收要求

- 完整窗口四阶段自渲染，人工查看视觉层级、分割线、文字、表单与分区。
- 普通窗口和 1280×760 窄窗口中保存操作、当前行和完整播放操作区保持可见。
- 保存按钮的可用 / 禁用两种状态，在 100% / 150% / 200% 离屏文字尺度下全部显示；测量字形边界、实际文字像素与至少 4.5:1 的对比度。
- 验证键盘保存、辅助功能名称、原生缩放和波形高度不改变字幕时间；继续验证撤销、保存重开、字幕渲染及原有制作流程。
- 使用程序自己的隔离实例和绘制接口；不通过 Computer Use 控制桌面。
- 生成独立的 0.4 运行包、对应源码和校验值，保留旧发行文件。

## 验收结果

- 0.4 原生集成 170 个检查点通过，包含全流程、四阶段窗口、1280×760 窄窗口、完整播放操作区、字幕渲染、保存文字及键盘 / 辅助功能验证。
- 392 项 C++ 测试（40 组）和 LuaJIT 回归通过。
- 人工查看全部四阶段整窗预览，以及保存按钮可用 / 禁用状态的实际字形。栏目标题另外检查实际绘制像素，避免空白渲染误判。
- 两种保存状态 × 三种文字尺度均通过完整字形边界、实际文字像素及 4.5:1 对比度检查。
- 原生缩放、波形高度控件调整后，字幕选区时间保持不变；音量包含静音并从保存的值恢复。
- 独立包验证由 scripts/test-package.py 执行；最终归档完整性、一致性与依赖检查由 scripts/check-release.py 记录到 build/release-v04-check.log，并生成 SHA256SUMS-0.4.0.txt。
