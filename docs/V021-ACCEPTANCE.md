# 声稿 0.21.0：时间来源与校对提示

对应完整待办第 3 组第五项。字符／单词参考、估算音节、歌声候选、人工调整与人工确认分别表达，避免把词组时间或整体平移后的估算当成逐音识别。本版沿用 TIFA 数值算法，不宣称提高了歌声识别准确率。

## 使用

在本句编辑区选词组或音节，起止框上方直接显示时间依据。点 **来源／提示** 查看整句、词组、音节各层级的当前范围、原始依据、来源服务、后续变更与提示。可筛选估算、歌声候选、人工调整或未确认提示；带前后音试听后，点 **去校准所选** 回到准确位置，不会先改时间。

审核自动建议时，在采用前显示内部仍有多少估算音节，可逐音试听。来源窗口本身只读；打开前若有有效输入，先按原流程提交，分词预览须先应用或取消。原版时间轴绘图与默认键位保持。

## 来源语义与保护

- 服务实际返回字符数组时保留字符参考，返回单词时保留词范围；单个汉字不能证明已得到演唱音素。词内新切分、按假名均分和没有逐音证据的重排仍为估算。
- 字符对齐可用作词组外边界，其内部假名仍可能均分。LLM 读音与翻译不提供声学时间。
- TIFA 真实音素区间保留对应输入假名。改读音后，旧声音依据不会被当成新假名的验证；来源页提示复核。
- 整体平移保留原始依据。比例／分段拉伸、固定阈值延尾及重叠整理后，当前范围标为变换后估算，原始依据仍可查看；锚点范围外实际只平移的部分按平移记录。固定规则不是休止识别。
- 直接手调边界记录人工调整，尚需确认。整体移动造成的人工保护只防止自动覆盖，不表示内部音节逐个校准；本版沿用现有保护规则，不自动解除锁定或旧人工标记。
- 确认时间与确认读音分开。时间确认后仍保留原始依据，取消确认、修改、保存和撤销使用同一工程数据。

旧项目缺少粒度时标为旧参考／来源未记录，不从单个汉字或旧人工标记推断精度。保留了固定 TIFA 模型音素区间的旧歌声记录，仅在原始参考范围逐项对应时只读恢复说明；手调后的当前位置、原始声音范围和对应假名分别保留。读音或参考范围不对应则提示复核，不改写原记录或请求服务。
