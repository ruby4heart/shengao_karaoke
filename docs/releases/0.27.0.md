# 声稿 0.27.0：整体校轴后重新计算内部

沿用“按本句原声／人声重算音节”。整体移动或旧确认产生了内部保护时，先列出哪些仍为旧估算、哪些是真正人工调整或锁定，再明确选择是否重算。已确认句还须单独允许重新计算；生成阶段保留当前时间与确认，试听并采用后才恢复时间待确认，读音状态保持。

来源明确的未逐音校准部分可按本地歌声重新计算，整句、人工词组范围、真正人工调整、锁定和固定点保持。失败区间恢复完整原数据，取消不解除保护；请求、任务恢复和暂存审核保留明确选择，迟到修改拒绝旧结果，一次撤销恢复重算前的时间与确认。未知旧人工来源继续保守保留并说明原因。已有人工边界可只读地用作局部范围参考，词组外缘与音节起止分别约束；部分计算失败不会记作完整缓存，明确重试仍可重新计算。
