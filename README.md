# 声稿 Karaoke Studio

Windows 日语卡拉 OK 字幕制作软件，使用独立 Qt 工作台。当前为 **0.25.0 开发版（发行验收中）**，面向个人非商业制作，尚未达到完整 1.0 验收标准。

**0.25.0 详细颜色与演唱状态**：分别设置待唱、演唱中和唱完留屏的正文、假名、罗马音及译文；文字、扫亮前底色、描边和阴影独立配色与透明度，描边／阴影可跟随扫亮。另有独立圆角底板、预设、指定歌词覆盖、视频帧预览和一次撤销。共用 ASS 渲染与导出路径，工程格式升级为 10；旧工程保持原有渲染，0.24.0 及更旧程序拒绝新版工程。尚待完整运行包验收，详见 [颜色实现范围](docs/COLOR-STATES-SPEC.md)。

**0.24.0 复用已校对副歌**：选择已经确认的来源句，复用分词、假名与罗马音，按目标段的实际歌声重新生成时间候选；不复制来源节奏、锁定或确认。目标人工内容、译文和原文保持，先审核，可保存和一步撤销；取消或失败保留候选及检查点。来源变化时不采用旧建议。此操作在本机执行，不使用 API 额度，歌声模型仍限个人非商业用途（CC BY-NC-SA 4.0）。

新工程格式为第 9 版，读取第 1–9 版，保存时间来源、变更、声音依据与人声资源。0.21.0 及更旧程序会拒绝第 9 版，请另存副本；旧任务快照和检查点兼容读取。

说明见 [第一次制作](docs/DESKTOP-USER-GUIDE.md)、[0.24.0 验收范围](docs/V024-ACCEPTANCE.md)、[0.23.0 整首顺序](docs/V023-ACCEPTANCE.md)、[完整待办](docs/WORKFLOW-TODO.md)、[构建步骤](docs/DESKTOP-BUILD.md)。每个功能项单独发行；旧包及原始 Aegisub 保留。自动候选仍需试听，整首成品与真人新手验收继续实施。

正式版缺项与完成标准见 [1.0 清单](docs/RELEASE-1.0-CHECKLIST.md)，当前余 **10 组、56 条功能／验收项**，含新增的待唱／演唱中／唱完详细颜色、描边、阴影及底板编辑，持续交付要求另列。从 0.21.0 起，每个完成的版本同时提交到本仓库，并在 [Releases](https://github.com/ruby4heart/shengao_karaoke/releases) 附 Windows 运行包、完整源码、公开验收和指纹；GitHub 自动生成的源码快照不包含大型第三方资源，构建请使用 Release 中命名的完整源码 ZIP。发布流程见 [GitHub 交付](docs/GITHUB-RELEASE.md)。

## 下载与使用

到 [Releases](https://github.com/ruby4heart/shengao_karaoke/releases) 下载对应版本的 `ShengaoKaraoke-X.Y.Z-final-win64.zip`，完整解压后双击 `shengao-karaoke.exe`。需要 Windows x64，无需另装 Python、FFmpeg 或 Aegisub。软件带不联网的合成练习素材，可先查看 [第一次制作](docs/DESKTOP-USER-GUIDE.md)。

1. 拖入视频，粘贴每行一句的原歌词；没有歌词时可先识别，再确认文字。
2. 配置需要的 ElevenLabs／Microsoft AI 转录及 DeepSeek 文字建议，审核自动初稿。联网动作会使用所配置服务的额度；已有结果可本地复用。
3. 可生成本地人声辅助，使用 TIFA 给原歌词生成待试听的演唱音节候选；在同一编辑区改分词、假名、罗马音与时间。原歌词始终保留。
4. 整体提前／延后、渐进漂移与局部校准均支持预览和撤销；上一句、本句、下一句共用刻度。确认时间与读音分别记录。
5. 选择日式双行注音样式，先压制样片，再导出 ASS 或 MP4，保存 `.sgproj` 以便继续。可给同一作品添加原唱／伴奏视频源并一键切换。

## 已有能力与限制

原版 Aegisub 音频绘图、波形／频谱切换、三个音频滑条和兼容音频键位保留；视频滚轮缩放、音节试听、建议审核、人工修改保护、自动恢复及内置字体和压制工具已接入。软件不启动 Aegisub 的主窗口框架。

自动分词、词典／DeepSeek 假名和歌声边界都可能需要人工复核。文字时间不能证明音素起点，TIFA 按输入读音强制对齐也不能证明该读音唱对。公开单一样本的误差不代表其他歌曲准确率；正式 MV 人工金标准、完整成品和真人新手验收仍在 [待办](docs/WORKFLOW-TODO.md) 中。

API 密钥由当前 Windows 用户的 DPAPI 加密保存在本机，不进入工程或源码发行。TIFA 权重限非商业用途；各第三方代码、字体、模型与运行资源的来源和许可随完整源码及运行包保留，不能把“正式版”理解为商用授权。
